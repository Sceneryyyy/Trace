# 05 · 现行界面与交互约束

适用 preview.35，2026-10-18。操作详情见 [28](28-USER-GUIDE.md)，最近实现与验证见 [89](89-FRONTEND-SIMPLIFICATION-ITERATION.md)。旧布局与阶段变更已存入[归档快照](archive/snapshots/05-UI-UX-before-archive-20261018.md)，不作为当前入口规范。

## 工作台与来源

- LeoMoon 原狮子月牙/字标保持，TRACE 小字可随仪表主题变色；不用竞品标识或素材。
- 同窗口显示实时、录音历史、固定缓存或文件。来源/真实格式/统计范围明确；时间码集中在走带，不重复铺满工具栏。
- 上下文设备入口直接显示设备名称、硬件名称、声道及源精度，长信息省略并保留完整悬停；录音格式与采样率为右侧只读信息区，采集率与录音预设不同时分别标明。监测状态由顶部状态与底部按钮显示；REC 或活动输出期间禁止修改相应设备配置。
- 实时、监测、REC 分开；历史查看不发声、不停止后台采集，发声输出才暂停输入。返回健康 LIVE 不重启采集。录音中可浏览，不发声回听或维护文件。
- 底部“重新开始本轮响度统计”图标紧邻“实时”右侧，随后是开始/停止监测；DOM 与视觉次序一致。保留既有 live.reset 行为及禁用条件（忙碌、未采集、录音中或文件视图），不置于文件管理动作右侧。
- 文件/成品/连续段/选区使用各自真实身份；查看、载入与回听不能因折叠/切分类/选版本被混为一个动作。

## 仪器、布局与设置

- 频谱对数轴投影保留密集频点的每像素峰值；稀疏像素列在相邻有效 FFT 频点之间按线性功率插值，不能将无频点的屏幕列当作静音。真实零功率点与全静音保留，不向有效 FFT 范围外推；悬停仍读原始频点。见 [92](92-SPECTRUM-CONTINUITY-FIX.md)。

- 2026-10-19 本地 preview.35 增量：声谱图采用 `mel-700-v2` 连续频率投影，2D/3D 轴、滚轮及拾取与 raster 共用映射；右侧纵向数值色阶使用同源颜色和 dBFS 范围。3D 按固定绘图区包围盒适配宽高，zoom 相对自动取景；保留现行时间窗、视角/高级区及游标。实现与验证见 [91](91-SPECTROGRAM-PORT-PREVIEW35.md)。

- 仪器标题保留最大化/恢复与“更多”，设置/隐藏位于菜单；隐藏可从“仪器”恢复。显隐与布局不影响录音/音频数据。
- “编辑布局/完成布局”明确动作；拖动/键盘停靠、分隔线调整、自动保存及命名布局预设保持。小区域可滚动或最大化，不裁切关键单位/故障。
- 波形、响度历史和声谱图共用游标/选区/时间范围。没有波形时声谱图仍可操作时间窗；3D 视角/相机复位与频率/色阶复位分别命名，高度/细节仅改变显示。
- “设置与帮助”分显示、录音与保存、行为、帮助与诊断、关于；分类共用草稿和单一应用按钮，录音/退出/主题参数应用后保存，Esc/关闭丢弃参数草稿并恢复原主题；选择录音目录沿用立即生效语义。录音中锁定录音参数，显示设置仍可操作；目标与布局独立保存。无单独的录音格式设置按钮。
- 五主题只改显示；红色故障/削波、琥珀警示保留文字/图标，历史 M/S/I 用不同线型，不仅依赖颜色。

## 文件、报告与比较

- 音频文件宽屏为 420 px 侧栏，阈值 1400 CSS px；窄屏为覆盖抽屉。录音/外部素材分开、每页最多 50 行，搜索/筛选/排序/类别/选中/页码/滚动在本应用会话保留。
- 单击/方向键只选择，Enter/“查看分析”载入不发声；行内回听/双击明确发声。当前文件回听保留用户选定的成品/连续段及游标/选区。
- 文件详情仅展开选中的一份版本，换版本不加载或发声。常用动作直出，管理/成品低频动作在菜单；取消/恢复/缺失定位按实际状态出现，质量警示始终可见。
- 原录音/成品移除保持确认与回收站语义，外部“移除引用”保留原文件/成品，清缓存保护唯一可恢复副本。
- 报告分测量报告/复核标记/分析图，切区保留草稿/选中报告/页码。标记绑定内容身份；图表类型＋格式＋单一导出动作，来源变动时拒绝过期保存。
- A/B 先引导选择来源；对齐/范围等高级参数可折叠且保留。等响度回听只在独立计量和质量就绪时启用，只衰减输出，不改变测量/录音/导出。
- 目标先选预设，自定义参数按需展开；I/M/S/LRA 的范围、有效时长和来源质量不能被折叠隐藏。

## 反馈、键盘与验证

- 一个当前文件主分析进度，图内简短说明。采集故障、文件故障和操作失败分别保留；成功通知不能盖掉未处理故障。
- 静音 `−∞`、测量中、分析中、重新连接、无数据明确区分；中断/估计静音/质量未知用文字警示，不把空数据/故障当成 0 或正常静音。
- 菜单支持方向键/Home/End/Enter/Esc/Tab 与返回入口焦点；模态/抽屉限定焦点，闭合 details 内控件不进入焦点边界。不能仅靠悬停提供功能。
- R 开始录音、Esc 结束录音或暂停回听、Space 播放/暂停、Home/End 起终点；输入/菜单/仪器内容/对话框焦点优先，全局走带不抢占输入。时间轴 Ctrl+D 清选区/循环，Shift 拖动选区，其余见 28。
- 前端布局覆盖 1024/1280/1600、1399/1400 阈值、列表开关、长中英文和五主题；浏览器光栅缩放不等于系统 DPI。真机听感/键盘辅助技术、GPU/DPI/对话框仍按 [76](76-RELEASE-CHECKLIST.md) 单列。
