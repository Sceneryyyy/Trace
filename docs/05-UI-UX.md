## 视觉值

背景建议 `#121615`，面板 `#1B211E`，分隔 `#303A34`，主文字 `#E6ECE7`，次文字 `#A8B5AC`；有效信号绿 `#91E65C`，游标青 `#58D4DA`，录制红 `#FF5E66`，注意琥珀 `#EFB65B`。字号和对比度在实际显示器验证；不靠颜色单独表达状态。

数值使用等宽数字，界面文字优先系统中文字体。数字通常保留 1 位小数，时间码与单位固定位置。大字号留给当前 I/M/S，整段统计不与当前值抢同一视觉层级。

## 工作状态

| 状态 | 顶部标签 | 波形/表头 | 按钮 |
| --- | --- | --- | --- |
| 无有效设备 | 等待来源 | 空状态，不生成随机波形 | 设备选择可用，REC 不可用 |
| LIVE | 实时监测 · 未录音 | 最近 30 秒滚动；live 累计 | REC、重置、FILE 可用 |
| REC | 正在录音 · 源信号 | 从 take 起点增长；take 累计 | 停止可用，回放/实时重置禁用 |
| FILE_PAUSED | 文件名 · 已暂停 | 游标处历史读数 | 播放、定位、LIVE 可用 |
| FILE_PLAYING | 文件名 · 回放 | 文件呈现时钟推进 | 暂停、定位、LIVE 可用 |
| EXPORTING | 与主状态并行的后台任务 | 主视图不强制跳转 | 显示进度、取消或重试 |
| SOURCE_ERROR | 设备/采集异常 | 保留最后位置并标“数据中断” | 重试/换设备；不能继续显示正常录制 |

FILE 暂停时电平保持在文件游标处，不继续按墙上时钟衰减。LIVE 的无声属于静音状态，设备错误属于数据缺失状态，两者文案不同。

## 时间轴动作

单击波形或响度历史定位同一游标，解除 LIVE 跟随。拖动查看历史读数，松开保留游标；若先前在播放，拖动会关闭输出，松开不自动发声。LIVE 跟随、历史游标、选区和缩放共用一套时间轴。

滚轮/快捷键缩放以游标或鼠标位置为中心，另提供“全长”和“跟随最新”。用户主动向前浏览录音历史后暂停自动滚动；点击 LIVE 再贴住最新位置。REC 中浏览历史仅查看图与读数，不发声回听。

Shift 拖动建立选区，左右把手可调整；显示起止和长度。选区循环仍显示文件历史，另显示选区统计，不把两者混成一个 I。导出选区使用独立成品任务和缓存。

## 保存设置弹层

顺序：格式 → 采样率 → 位深或码率/质量 → 目录/文件名 → 是否另存原始 WAV。WAV 显示“跟随来源”与 16/24-bit、32-bit float；MP3/AAC 显示 44.1/48 kHz 与编码设置，不提供“24-bit MP3”。AAC 明确 M4A/ADTS 封装。

下方实时摘要：`采集 96 kHz / 双声道 → WAV 96 kHz / 24-bit` 或 `采集 96 kHz → MP3 48 kHz / 192 kbps`。预计空间包括临时源文件。录制中修改设置标为“下次录音生效”。

不在界面放“PCM 队列”“N-API”“缓存 schema”等实现术语；用户能看到的是录音是否完整、文件是否准备好、参数是否发生转换。

## 键盘与错误文案

Space 播放/暂停，Home 回文件开头，R 开始录音，Escape 停止当前录制或播放；文本编辑焦点下不触发字母快捷键。首次有破坏性覆盖风险时通过另存文件名解决，不用默认覆盖。

| 情形 | 建议文案/动作 |
| --- | --- |
| 输出设备断开 | “录音设备已断开，已保留可用录音。”提供重连 |
| 磁盘写入拥塞 | “录音已停止：磁盘未能及时写入。”定位异常位置 |
| 已停止但成品未就绪 | “正在生成 MP3，原始录音可先回听。” |
| 分析尚未覆盖游标 | “该位置正在分析。”不显示伪造数字 |
| LRA 素材过短 | “LRA 暂估，录音长度不足以稳定评估。” |
| 历史返回 LIVE | 跟随最新；正在运行的采集与累计不重启 |
| 恢复未完成录音 | “发现上次未完成的录音，可恢复已保存部分。” |

验证目标包括焦点、键盘、数值单位、缩放与两图同步，详见 A12。

## preview.3 滚轮与文字精简

波形区域 Ctrl + 滚轮为 5–60 秒时间窗；普通滚轮为 ×1–×4 波形显示倍率。即时显示最新目标，后台命令按维度合并，旧回复不覆盖新目标。已到边界不重复发命令。波形与响度共用窗口；FILE/HISTORY 全长另作完整概览，短文件以实际长度为限。LIVE 滑杆可直接输入同一范围；REC 保留全长与跟随，缩放不影响写盘。

TP 行直接标注 dBTP；删去重复的计量解释、常驻“不保存音频”说明与设备空闲估计静音文案。LRA 保留必要的暂估标记；详情、缩放提示进入悬停/帮助。常规状态用简短标签，音频中断和分析中提示仍保留。
