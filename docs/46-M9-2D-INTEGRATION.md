## 当前行为

- 新增“声谱图”仪器与“时频检查”预设；workspace v3 从 v1/v2 迁移，保留原位置、可见组合及自定义预设，新仪器默认隐藏。
- 2D 与波形/响度历史共用 Timeline：点击定位、Shift 拖选、刻度轴选区、Ctrl＋滚轮时间缩放、Shift＋滚轮文件平移。布局改变不控制音频生命周期。
- 纵轴为频率，色阶为 dBFS 幅度；普通滚轮缩放频率。独立设置保存 FFT 窗、声道、频率/色阶范围及 Trace/热度配色；复位只影响频率和色阶。
- 悬停查询原始 bin，显示实际 FFT 窗结束时刻、Hz 与 dBFS。画面色块为覆盖时频范围的最大值，二者不混用。未覆盖/缺口使用斜纹，静音保留有效覆盖及 −∞ 语义。
- 文件、实时、当前录音段及固定缓存均有来源解析路径。REC 通过 SessionTimeline 在统一纳秒轴和当前原生段之间映射，不把纳秒当 PCM frame。
- 实时范围当前每 500 ms 请求一次；包携带实际绘制起止，旧数据不会被拉伸冒充最新时间。实时显示延迟和长范围首次准备仍须专项测量/优化，不能把短 GUI 通过当成已达成全部响应预算。

## 数据流与生命周期

新增白名单命令 spectrogram.configure/query/point/cancel。query 仅接收来源引用和有界显示范围，不接收文件路径；point 关联已接纳的 queryId。配置校验独立于布局。

图像数据通过 trace:spectrogram → preload 单次 ArrayBuffer 转移 → window.trace.onSpectrogram 分发，支持请求 ID 关联与过期淘汰。该数据流不保留旧图像，也不把大数组塞进已有 256 份命令回复缓存。重复注册同一监听函数可以分别移除。只读查询错误不会触发录音/分析恢复操作。

SpectrogramPresenter 管理当前请求及来源绑定。PlaybackService 打开/关闭来源时，先撤销当前上下文并等待声谱任务释放；缓存清理和库删除沿用该关闭路径，之后才执行文件管理。退出等待所有任务，隐藏/最小化或隐藏面板时取消呈现查询。

文件已有验证后的分析键时，使用持久分块缓存。分析尚未完成时先使用本次打开身份和内存缓存，避免等待全文件计量；验证完成后换到内容绑定的缓存。该临时身份不跨启动写盘。外部素材替换检测和完整导入工作流仍归 M12，现阶段仅处理应用已解析的来源。
