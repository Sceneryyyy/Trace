# 48 · M10 同数据 3D 声谱图设计

2026-09-17。M9 共轴时频数据已经通过数值/服务/界面专项，preview.17 资源门禁与录音完整性已通过，M9 工程关口关闭。独立几何、相机、拾取和 WebGL 生命周期验证已通过；产品入口、录音场景与降级已接入，当前状态见 49。

## 选型与来源

采用现有 Electron 内的 WebGL 2，自建一个小型渲染层，不增加 Three.js 等运行依赖。锁定的 Electron/Chromium 继续作为运行环境。上游 Spectrogram.ts 使用 AudioRouter 的流式 2D 数据与不同显示选项，不符合 Trace 的文件/固定缓存/同位置恢复契约，因此仅作视觉参考。

已核对 [Khronos WebGL 2 规范](https://registry.khronos.org/webgl/specs/latest/2.0/)和 [WEBGL_lose_context 文档](https://developer.mozilla.org/en-US/docs/Web/API/WEBGL_lose_context)。前者 latest 为编辑草案，实际 API 能力还以当前锁定运行时实测为准。设备丢失后旧图形资源失效，恢复时重建 program/buffer；用户返回 2D 或隐藏组件时释放自己持有的资源。

本机隔离探针确认 WebGL 2 可用：ANGLE / NVIDIA GeForce RTX 4080 SUPER / D3D11，MAX_TEXTURE_SIZE 16384，支持丢失/恢复扩展。证据 artifacts/m10/gpu-probe-1789586038788/report.json；不据此推断所有用户 GPU 均支持。

## 数据与解释

- 复用 M9 SpectrogramView，不重建另一条 FFT/计量路径；原始点查询仍经 spectrogram.point 返回真实 FFT 窗和 bin。
- x 为时间，z 为频率（沿用对数频率比例），y 为 dBFS 的显示高度；3D 不代表声源在房间中的空间位置，也不使用 LUFS 标签。
- 细节有 64×32、128×64、256×128 上限。每格对其覆盖的 M9 显示单元取最大值；原始 dB 保留在 CPU 网格旁，不以投影后的坐标反推测量。
- 未覆盖/缺口格不连接表面三角形，避免跨缺口造出连续曲面。静音具有有效数据和底部平面；空白范围通过状态说明区分。
- 网格按包的实际时间范围映射到当前共用视口；旧窗口的数据可以保持正确坐标，但不能伸展成当前时间。极端缩放导致无法可靠映射时等待新网格。
- 鼠标拾取最近可见三角形，获取时间/频率坐标，再查询原始点；没有表面时可落到基准平面，并保留原始点的未就绪/缺口状态。

## 操作与状态

- 同一“声谱图”仪器内切 2D/3D，不创建 FILE/LIVE 新页面，不切换音频来源。
- 拖动旋转，滚轮缩放相机；正面/侧面/斜视/俯视预设，视角复位，显示高度和细节设置。
- 底部保留线性的共用时间刻度，用于定位、拖选区；时间范围仍由全局时间轴/走带控制。旋转不移动游标、不改变 FFT。
- 3D 沿用全局游标和选区标记；频率、时间和 dBFS 轴提供文字/单位。相机设置与纯显示选项持久化，旧设置迁移后默认 2D。
- 初始化失败/上下文丢失时显示可读原因并使用 2D；保留当前来源和计量。恢复重建图形资源，或由“重试 3D”新建上下文。错误不能结束录音或重新累计 I。

## 资源边界

- 最大 32,768 顶点、64,770 三角形；当前 CPU 网格约 1.03 MiB，顶点/索引 GPU 数据约 0.87 MiB。一个 renderer 持有 3 个 buffer、1 个 program、1 个 VAO。
- Buffer 容量按需增长，后续较小网格复用容量；旋转/缩放复用同一网格，资源数不随操作次数增长。
- Drawing buffer 上限 4,194,304 像素，并遵守 MAX_RENDERBUFFER_SIZE；DPI 超出预算时降低图形绘制分辨率，不改变测量与原始点查。
- 几何建立与拾取预算分别以标准/最大网格测量，不能让绘图阻塞音频采集；当前独立最大网格建立约 9 ms、拾取约 1.4 ms，尚不是完整产品运行结果。
- 图形资源丢失及销毁路径独立验证；后续集成补反复切换、窗口/DPI、REC 中丢失恢复、无 WebGL 的 2D 降级及长时间资源测试。

## 当前独立验证

`test/spectral-surface.test.mjs` 4 项通过：同数据最大值/静音/缺口、全部相机预设与投影反解、可见表面拾取、最大网格存储。输入 dB 数组保持不变。
