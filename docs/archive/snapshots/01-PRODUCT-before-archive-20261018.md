## 目标与用户工作流

## 第一版默认值

| 项目 | 默认行为 | 原因 |
| --- | --- | --- |
| 设备 | 首次显示系统默认播放设备；选定后绑定其 ID | 默认设备变化不应悄悄改变正在录的内容 |
| 声道 | 原生单/双声道；超过 2 声道先明确不支持并提示换设备配置 | 不把前两个声道误称为完整多声道录音 |
| 主视图 | 同窗口可配置仪器工作台，明确标注实时、录音历史或文件来源 | LIVE 跟随与历史查看同屏；发声回听单独控制 |
| 同录同播 | 首版不支持；先停止录音再回放 | 避免自身回放进入系统采集 |
| WAV | 跟随来源，24-bit PCM；可选 16-bit、32-bit float | 高采样率原样保存，明确可选位深 |
| 手动 WAV 采样率 | 44.1/48/88.2/96 kHz | 更高采样率不在首版承诺范围 |
| MP3 | 48 kHz、192 kbps CBR；可选 44.1 kHz、128/192/256/320 kbps CBR；当前无 VBR 选项 | 压缩输出可调；不冒充 PCM 位深 |
| AAC | AAC-LC、M4A、48 kHz、192 kbps；可选 44.1 kHz及经验证码率，另提供 ADTS .aac | 默认文件回放工作流；两种封装明确区分 |
| 保存后处理 | 需要转换时后台生成成品并显示进度；保留可恢复的临时源文件 | 停止录音不等于所有编码已完成 |
| 监听 | 仅 FILE 回听输出，音量独立；LIVE 不再转发一遍系统声音 | 系统声音本来就在播放，避免叠音 |
| 目标线 | 可关闭或自定义；只提示，不自动改音量 | 目标值与测量本身分离 |

## 核心状态

LIVE 持续采集、分析、显示，不创建音频文件。REC 复用同一采集流，从引擎确认的起点创建 take 和其独立统计；未按 REC 前的音频不写入。停止录音回到 LIVE，继续当前 live 统计；take 的结束边界固定。

选择文件只加载数据到同一工作台，后台 live 继续；拖动游标查看历史不发声。按播放时才暂停采集，回听输出不会进入实时统计；暂停、拖动或结束后按原意图恢复采集。点击 LIVE 跟随最新，健康输入不重启。尚在后台编码时可查看已准备的原始录音，不自动切换成品。

## 首版历史边界

M0–M6 时不包含 VST3/AU 插件、DAW ASIO 输出保证、同时录多个设备、混音器、5.1/7.1、录制中回听、缓存保存、连续 scrub 发声、降噪/效果器、频谱全套、账号/云服务。后续 preview.9 已加入显式缓存保存，M8–M12 已加入频谱/声场、2D/3D、报告、外部导入与参考比较；这些历史排除项不撤销后续已交付能力。其余未支持项仍按当前产品范围处理。

完整首版是 M0–M6 的退出条件全部满足。M1 的实时监测原型、M2 的 WAV 原型不能单独宣称“项目完成”。关键 Windows 验收必须留下版本、设备实际格式、素材和结果；未运行项不能按通过处理。
