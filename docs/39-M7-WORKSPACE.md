# 39 · M7 仪器工作台架构与实施记录

2026-09-16。M7.0 已完成架构/源码审计，开始 M7.1–M7.3。基线提交 5c09c73，preview.9 原 ZIP 校验通过，当前产品代码类型检查与原 92 项 JS 回归通过（artifacts/m7/baseline.json）。用户已授权持续推进至 M12、复评并继续改进，以及按阶段提交；无需每阶段重新索取开工确认。人工验收与未验证硬件继续分栏记录。

## 1. 决策

采用原生 React/CSS 分割树，不引入停靠组件依赖。树节点为 row/column、比例及两个子节点，叶子为稳定仪器 ID。渲染时折叠隐藏叶子，保持保存的树不变。最大化是临时呈现覆盖，恢复回原结构；锁定时禁用布局编辑。标题拖动停靠和菜单移动提供同等功能；分隔条支持鼠标与方向键调整。全部隐藏仍保留仪器选择入口。

首批叶子为 levels、waveform、history、loudness。原 Timeline 拆为两个呈现实例，共用主应用的来源/游标/窗口/选区，拖选预览共用 context；SelectionStats 保持全局选区摘要。每个仪器有相同的标题、单位、设置、最大化和隐藏控件。布局编辑不触发播放/采集命令。

布局状态通过新的 workspace.configure 白名单命令写入现有 trace-settings.json；字段 workspace 独立于 displaySettings、recordSettings、monitoringRequested、deviceId。无字段的旧设置加载默认布局；坏布局只回退 workspace，不丢弃其他设置。持久状态包含 current 与最多 20 个自定义预设，名称最多 40 字；严格校验叶子唯一、完整、树深、ratio 和布尔值，避免畸形/巨大 JSON。

主应用继续拥有 HistoryPresentation 与 PlaybackService 对应上下文。面板重挂载只改变显示组件；不会重置 native engine。计算配置、目标线仍在独立字段。面板设置为纯显示选项：声道电平显示、响度紧凑/完整、历史 M/S/I 可见性。未来 FFT 等影响结果的设置单独定义版本。

## 2. 模块

- src/trace/workspace.ts：仪器注册与纯布局操作、严格校验、迁移/默认状态。
- src/trace/renderer/InstrumentWorkspace.tsx：面板框架、仪器选择、布局预设管理、分隔条、停靠与键盘替代操作。
- src/trace/renderer/Timeline.tsx：可单独绘制 waveform/history，共享拖选预览、统一坐标与旧交互。
- src/trace/renderer/App.tsx：组合现有数据与新仪器，不转移 REC/设备责任。
- src/trace/shared.ts、contracts.ts、main.ts：白名单和持久状态。
- styles.css：面板布局保底；独立 instruments.css 放统一仪器样式，避免继续散加互相覆盖的规则。

## 3. 显隐、历史与边界

| 行为 | 显示 | 音频与统计 |
| --- | --- | --- |
| 隐藏面板 | 卸载 canvas/ResizeObserver，停止该显示消费 | 采集、REC、核心计量、60s PCM 不变 |
| 恢复面板 | 读取最近已呈现快照；未来仪器按窗口补建 | 无额外设备重启 |
| 调整/停靠 | 重排/重绘；指针捕获限制到标题/分隔条 | 不发 seek，不改变窗口或选区 |
| 查看历史 | 所有可见仪器查询同一呈现上下文，各有明确计算窗 | 查看不发声；同位置可重复 |
| 慢分析 | 只接纳来源/代次/配置匹配结果，等待状态明确 | 不混入旧结果，不假造正常静音 |

布局编辑时标题负责拖动，图内交互保持原职责；树最大深度 8。缩至最小窗时面板内部可以滚动设置或紧凑读数，不允许关键来源和走带被挤出窗口。保存布局不包含瞬态最大化；恢复默认不清除自定义预设。

## 4. 上游复用审计

锁定 Prism df0755b。保留原代码与许可证，不在 M7 修改 DSP。

| 文件/模块 | 已确认机制 | 决策 |
| --- | --- | --- |
| native/src/dsp_utils.cpp 的 DSP::FFT | radix-2，预计算 twiddle，复用 buffer/scratch；输入 size 没有完整安全校验 | M8 可复用算法基础，外围限制 FFT size；独立数值参考验证 |
| native/src/spectrum.cpp | 每次 push 后处理最新窗口；固定 smoothing 递推依赖 push 次数；Hann coherent gain 修正；钳制 dB | 不直接复用其整套历史状态；采用固定 hop/时轴，平均/保持按样本窗口定义 |
| native/src/spectrogram.cpp | FFT 与配色强度、倾斜、重分配和屏幕行映射耦合；返回动态 display/heat vectors | 参考映射/绘图，不作为 Trace 原始历史数据；M9 用独立、未着色、带帧坐标的频谱块 |
| native/src/vectorscope.cpp | 固定 8192 样本环、左右样本及多频带缓存；无 Trace epoch/资产定位契约 | 复用坐标思路，历史由固定样本时间窗读取；不沿用设备无关固定余辉时长 |
| src/renderer/visualizers/* | 依赖上游 app store、显示配置和推流 | 参考标尺/视觉，不直接嵌入 Trace 页面或引入其系统音频路径 |

上述代码存在不表示 Trace 已有对应功能。M8 将建立真实数值/帧边界/随机查询验证，后续必要算法信息进入 03/04/06。

## 5. 资源预算 v1（实施前目标，尚非测试结果）

基准：本机 i9-14900K / 32 逻辑处理器 / 约 128 GiB 内存；记录 Windows 与实际设备格式到每份运行报告。既有 preview.9 长文件资源报告 artifacts/m6/resources-latest.json 仅作为旧基准；不冒充本轮长测。

| 项目 | 初始预算/限制 |
| --- | --- |
| 被动 PCM | 每个活动采集流最多 60s；96k stereo float32 单份约 44 MiB，固定/保存副本沿用有界并发，相关总预算 192 MiB |
| 新增实时 FFT 历史 | 128 MiB 上限，固定 hop 和实际样本率；超过预算先减保留分辨率/按需重建并明示覆盖，不能丢录音 PCM |
| 文件 FFT 读取/预取 | 64 MiB 缓存，上限 2 个后台分析任务、单一录音写盘优先；整文件在磁盘 |
| renderer 测量数据 heap | 128 MiB 增量上限；单消息数据预算 4 MiB、最多 2 个窗口请求待决，旧请求取消 |
| 绘图/GPU | 192 MiB 数据/纹理预算，当前可视区网格，隐藏即释放；新增绘图资源必须在复开循环后趋稳 |
| 工作集 | main 含 native 目标 ≤600 MiB；应用总工作集目标 ≤1.5 GiB，超标记录并阻断相关交付 |
| 更新 | 一般仪器 30 Hz，录音/计量不随 UI 降频；最小化 5 Hz 以下或停止绘图 |
| 响应 | 延用 08：缓存命中 p95 ≤100 ms、输出缓冲校正后呈现偏差 p95 ≤50 ms；首次分析独立记录 |
| 布局 | 最多 20 个预设、树深 8、M7 的 4 个仪器（未来扩容需要设置迁移）；配置序列化 ≤64 KiB |

预算随实測结果经记录调整，但不能在失败后不说明地放宽。涉及 FFT 分辨率/窗口范围的降级不是纯视觉选择，必须保持准确查询与明确状态；如果无法提供所需窗口则显示不可用。静态装饰/相机变化不失效音频缓存。

## 6. 视觉和交互方向

保留 Inter/JetBrains Mono 与 TRACE 标识，背景/面板改为中性石墨灰，绿色为信号和实时，青色为游标/选区，红/琥珀为异常与目标提示。顶部品牌缩至 42px，设备/来源行紧凑处理；仪器头统一约 32px，关键单位目标 ≥11px。最大/紧凑响度切换不平滑或插值 LUFS。

UI/UX Pro Max 的首次系统检索返回偏营销页面，未采用其 Hero/CTA/配色。使用既有产品与手册图作视觉依据，采用其拖动替代操作、可见焦点与非纯颜色状态原则；本文件不是通用网站设计套用。
