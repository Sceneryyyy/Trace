# 29 · preview.2 人工反馈改进

日期：2026-09-16。版本：0.1.0-preview.2。

用户反馈：LIVE 希望临时回听约 60 秒；刻度轴无法直观选择循环范围；文件列表缺少管理入口，外部删除后状态没有同步。

## 1. LIVE 内存缓存与 HISTORY

- 新增 ReplayBuffer，实际采样率 × 60 秒 × 实际单/双声道 float32 PCM；每个计量发布帧同步保留完整数值、波形与响度标记，记录容量固定 6002。
- PCM 在原生分析线程从完整块进入，不经 JS，也不进入 REC writer 路径。初始化预分配，持续处理不增长容量。
- LIVE、REC 都可以继续积累该有界缓存；只有未录音时可以进入 HISTORY。
- “回听缓存”先停止采集并排空分析，再冻结最近连续音频。原生 WaveSequence 增加内存数据源，复用既有呈现时钟、seek generation、音量与循环逻辑。
- 主表头恢复采集时的历史，I/LRA/Max TP 属于原监测累计；不从缓存起点重新计算后冒称旧读数。
- 选区独立统计使用相同 Meter 后台处理，每次最多一个运行任务，后续请求合并到最新范围；旧来源结果不覆盖新来源。
- HISTORY 明确标为临时缓存，没有成品导出入口。全程不创建 PCM/WAV/压缩或磁盘分析缓存。
- 设备变化、用户 reset、数据缺口会重新建立缓存；不跨未知缺口拼接。
- 返回 LIVE 后重新开始监测与缓存。现阶段不做“边回听边继续采集”，防止自身回放进入系统录音。

ReplayInfo version 1，包含冻结区间帧数、原监测帧偏移及真实采样率/声道。Meter v4 与磁盘 cache key 3 不变。

## 2. 选区与循环入口

- FILE/HISTORY 两图之间的时间刻度轴可直接拖动选区。
- 显式“定位 / 选区”模式；选区模式中在波形或响度图内直接拖动。
- Shift 拖动和起止秒输入继续保留，拖动不是唯一操作途径。
- 设置范围后勾选“循环”，再点击播放或按 Space。两图和统计共用同一范围。
- REC 中仍只浏览图与概览，不加入录制中回听。
- 小窗口检查修正新增工具行、走带和文件列表操作列占宽。保持现有深灰/绿/青色视觉体系。

## 3. 文件管理与磁盘同步

- 新增 LibraryService；availability 与录音/导出 phase 分开。
- 打开文件列表、切回列表所在窗口、列表打开期间每 5 秒，以及手动刷新时核对实际文件。刷新请求合并，避免长操作时排队增长。
- 外部删除/移动标记 missing；权限或无效路径标记 unavailable。禁用不可用资产的回听、分析与另存。
- 缺失某个分段不会把剩余分段静默拼成完整录音；恢复原路径后再次刷新可恢复可用性。
- 搜索名称并按 50 项分批展示；列表有“移除录音”“移除成品 / 清理失效项”。
- 移除前由主进程展示范围，默认取消。调用系统回收站，不用永久删除替代失败的回收站操作。
- 成品移除仅针对其目录；整条录音移除会包含源音频、成品及缓存。正在回听该目标时先关闭回听；相关分析和保留任务先停下。
- 拒绝符号链接/目录跳转、未注册范围和被替换的会话身份；移除前重查 sessionId/exportId。磁盘目录已经不存在则清理记录，不重新创建目录。
- 移除失败保留记录，成功后更新列表。管理结束后恢复分析/导出调度。
- “另存副本”在独立位置，删除副本不影响 Trace 内部成品。界面和指南明确说明。
- 修复成品“分析”入口没有传递 exportId 的遗漏。

## 针对性验证

- 原生 CTest 12/12；新增 replay target 内含 8 组检查：
  - 44.1/48/96 kHz × 单/双声道，67 秒确定性样本验证 60 秒覆盖边界与逐样本读取。
  - 冻结副本不随后续写入改变；reset 清空缓存。
  - 与统一 Meter 发布的真实历史逐项比较，重复查询 I 与 TP 精确一致。
  - 选区与独立切片分析结果相同。
- LibraryService 7 项：删除/恢复、另存副本与内部成品、可恢复移除、缺失目录不重建、录音占用与 junction 保护、身份替换/缺失归属记录时保留文件，以及确认期间自动编码刚开始的并发保护。
- 实际 Electron/WASAPI 65 秒测试 8 项：缓存不超过 60 秒且不写音频；与原 LIVE 同索引读数一致；十次循环后历史不变；返回 LIVE 重置；刻度轴/显式模式拖选并循环；外部移除/恢复；取消与确认成品回收站操作；整条会话回收站移除和回听收尾。
- 所有删除测试只使用 artifacts 中生成的测试会话；运行测试的确认响应预先控制，真正的目录移除调用 Windows 回收站。

实机 65 秒段以当前端点空闲静音为主；信号样本精度与 I/TP 数值另由确定性原生素材验证，不把这些自动检查当作用户听感验收。
