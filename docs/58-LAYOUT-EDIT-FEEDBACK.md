# 58 · 布局编辑入口反馈

日期：2026-09-17。版本：Trace 0.1.0-preview.26。

## 问题与结果

用户打开仪器后无法直接发现布局调整入口。“已锁定”只描述状态，没有说明点击后的动作；“自定义 · 未保存”容易被理解为当前排列没有持久化。

- 普通状态显示铅笔图标与“编辑布局”；编辑状态显示勾选图标与“完成布局”。完成后锁定位置与尺寸。
- 编辑时显示简短操作提示、标题拖动把手和分隔线手柄；结束编辑后收起这些提示。
- 保留拖动停靠、鼠标/键盘调整尺寸及仪器设置里的“移动仪器”。编辑时设置按钮的悬停说明包含移动功能。
- 未绑定预设的排列显示“自定义布局”。管理弹层说明当前排列自动保存，另存命名预设用于以后切换。保存失败仍有原来的错误与重试入口。
- 不更改布局数据格式、预设持久化机制或音频处理。M12 评分保留为此前专家评估，未因这次修正提高分数。

## 验证

类型检查与 Trace 构建通过。`tools/feedback-layout/ui.cjs` 使用实际打包界面、独立配置和生成的音频文件，没有启动采集或发声回听。四组流程通过：

1. 编辑、鼠标/键盘调整尺寸和浏览器停靠不改变文件来源、游标、选区或监测意图。
2. 菜单移动、命名预设和当前自定义排列可分别操作。
3. 1024×700 / 1600×950，分别按 1 / 1.5 / 2 倍渲染，共六组；无页面横向溢出，标题和编辑入口完整，结束编辑后提示与把手收起。已查看小窗口和较大窗口截图。
4. 重启恢复当前自定义排列，命名预设仍可独立召回。

通过报告：`artifacts/layout-feedback/ui-1789617755673/report.json`。前两次检查错误地比较了内层分隔线操作与外层布局比例，造成超时；指针事件已送达正确分隔线。改为核对实际分隔线的比例后通过，原失败报告保留。

包审计四项通过。`tools/feedback-layout/package.cjs` 验证 97 个包文件、ZIP 完整性，以及全部八个 main/worker/preload JS 除版本号外与 preview.25 一致，原生模块字节一致。报告：`artifacts/layout-feedback/package-1789617725981/report.json`。

本次未重跑 30 分钟资源流程、真实设备专项或完整音频矩阵；这些路径未改动。六组缩放是渲染检查，不替代混合显示器实机验收。实际用户体验仍待用户复验。
