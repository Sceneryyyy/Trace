# 50 · M11 目标、事件与报告设计

2026-09-17。M10 GPU 关口修复期间，独立推进不依赖图形的目标和报告数据层。当前目标规则、缓存逐块遍历、事件合并及 HTML/CSV 生成已独立验证；尚未接入产品界面或报告任务管理，不表示 M11 已交付。

## 目标与标准来源

TargetSettings 独立于布局与 FFT：启用状态、整段 I 目标/容差、True Peak 上限、可选 LRA 范围、可选 M/S 上限。修改目标只改变比较结果，不修改缓存测量，也不归一化音频。

已阅读 [EBU R 128-2023 原文](https://tech.ebu.ch/docs/r/r128.pdf)。当前条款 h 给出 −23 LUFS 和实际难以达成时的 ±1 LU；条款 i 为 QC 测量工作流提供 ±0.2 LU。不能把文件历史页中的旧 ±0.5 LU 修订记录当成当前正文。线性制作的 TP 上限 −1 dBTP；文档没有规定通用 LRA 上限，且短于一分钟不建议用 LRA 做判断。

据此提供带版本/URL 的“EBU R 128 · QC”和“EBU R 128 · 直播参考”，以及自定义目标。预设被修改后必须变为自定义，不能保留错误的标准名称。预设只表示目标数值参考，既有 EBU 原始素材与设备专项仍独立开放，不据此宣称认证合规。

同时发现 ATSC A/85 已在 2026 年更新；[官方入口](https://www.atsc.org/atsc-documents/a85-techniques-for-establishing-and-maintaining-audio-loudness-for-digital-television/)与旧版说明并不相同。当前不把尚未核对的对白/节目口径合并成一个 A/85 预设。

## 范围与结果含义

- 完整文件报告使用完整缓存的汇总；选区报告使用该选区独立分析缓存，从选区起点重新累计 I。
- 报告记录原文件逻辑帧范围与缓存物理解码范围，二者必须匹配；不把编码器填充帧或选区前缀混入。
- 目标判断使用未四舍五入值。静音保持 null + silence：对 TP 上限可以满足，对 I 下限不能满足；不足/缺口/错误不可当成 0 或通过。
- 请求 LRA 判断但范围短于 60 秒时，保留读数并标为不能判定。全部判定项未启用时为 disabled。
- 录音完整性与文件分析完成是不同概念。源完整性未知或有缺口时，不能因为现有数值符合目标就给出完整通过结论。

## 事件和 CSV 时间分辨率

AnalysisCache.reportRows 逐页读取原缓存，不使用绘图降采样数据。电平/TP 为 10 ms 窗，M/S/I 为 100 ms 快照；每行记录实际 level/loudness 索引帧。首次 M/S 未就绪不等于音频缺失。

连续相同事件合并，恢复、缺口、错误会断开。TP 分声道；I 高/低事件明确是“截至此处 I”，不能替代最终整段结论。M/S 上限仅在用户指定时启用。跨两个响度快照之间的缺口也会切断事件，不将旧值连接成正常连续数据。

事件保存观察窗口 [start,end)，不是样本级越界时刻。完整事件 CSV 按结束顺序流式写入；UI/HTML 的有限预览可以按起点排序。

## 输出和安全边界

一次报告包含 report.html、summary.csv、history.csv、events.csv。HTML 提供范围、目标结果、整段/选区 I/LRA/TP、事件预览及来源/引擎/分析 hash；最多展示 1000 个事件，完整内容保留在 CSV。历史 CSV 保存原始数值与状态，缺失值留空，不写假零。选区 CSV 帧号映射回原文件逻辑坐标。

报告不嵌入音频，也不暴露内部源文件绝对路径。HTML 文本转义，CSV 文本防止公式注入，数值列保留原精度。文件名/标签来自用户数据，不视为指令。

生成前核对实际测量 PCM 的 SHA256，扫描后再次检查文件状态；读取过程中使用原缓存的页校验。输出写入新的任务目录，已有目录拒绝覆盖；失败/取消只清理本任务创建的固定输出文件，原音频与已有报告保留。读取与写入采用有界缓冲，不把长录音或全部事件加载进内存。

## 接入工作

M10 关口关闭后接入目标设置与旧目标线迁移、统一图表反馈、报告后台任务/进度/取消/重试、事件分页及跳转、报告导出。原始缓存和目标快照分别绑定；目标改变后旧报告标注需要重新生成。清理/删除源缓存前等待报告读取释放，保留独立任务租约。完整 UI/长文件/异常/包验收完成后才能关闭 M11。
