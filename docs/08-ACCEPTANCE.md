## 测试素材

1. EBU Loudness Test Set：按其条款取得、记录具体版本、文件和参考值，不把未知素材当 oracle。
2. 自制确定性 PCM：全零、997 Hz 正弦、左右独立信号、单脉冲、跨块瞬态、阶跃、头尾脉冲、长静音、接近满幅及浮点越界信号。
3. 单声道/立体声与 44.1/48/88.2/96 kHz 的必要组合；先覆盖实际承诺，再扩展其他率。
4. 用小数据段上限触发分段与恢复，不必每次生成数 GB；发布前另做真实长录音。

可用解析公式验证基本峰值/RMS：未削波单正弦的 RMS 比幅度峰值低约 3.0103 dB。此关系不适用于 LUFS 和 True Peak 标准合规判定。True Peak 必须有能区分样本峰值的参考素材。

## 容差与比较口径

官方参考测试使用素材自身规定的容差。自制 PCM 同样本率/格式直通，样本数及边界必须精确相等；float32 源同样本率 float32 写出应保持样本表示，无 DSP 路径不得出现额外归一化。整数/抖动/重采样/有损输出不能要求 bitwise 相等，改核查格式、帧映射、独立解码结果和合理数值差。

相同缓存同一索引重复读取必须相同；跨算法 build 的数值比较按声明的测试容差，不能用截图肉眼估计。比较上游 Prism 或 Insight 2 时固定来源、输入增益、标准、声道、窗口和峰值保持；它们不能代替官方参考值。

任意 seek 的 LUFS 查阅为最近的历史索引，Meter v5 默认 10 ms；标准数值容差独立于索引精度。对于声音/图形同步，初始工程目标是扣除已知输出缓冲后 p95 显示偏差 ≤50 ms、缓存命中定位响应 p95 ≤100 ms；在基准 PC 实测后记录适用设备条件。这些是产品目标，不是已有性能声明。

## 故障细分

| 故障 | 检查重点 |
| --- | --- |
| writer 队列满 | 结束录音并标异常，不能覆盖旧 PCM 后继续报完整 |
| analysis 队列满 | 源完整时可离线补建；take 统计先标无效/分析中，不能把重开累计当原 take I |
| 无应用播放 | 空闲静音时长与恢复帧对齐，不能由每次轮询误补零造成漂移 |
| 源 96→48 kHz | 新 epoch/新段，边界及缺口清楚；同一 WAV 中不混格式 |
| 硬杀进程 | checkpoint 与实际完整帧核对，修复副本不毁唯一源；注明丢失尾部 |
| M4A 未完成 | 不假设可像 WAV 一样补头恢复，临时源仍在 |
| 旧 seek 晚返回 | generation 阻止其移动新游标或播放旧音频 |
| 文件替换/改编码 | 内容标识改变触发独立分析，旧缓存不命中 |

## 资源目标

LIVE 算法/显示缓存在稳定后不随运行时长线性增长；完整文件历史只保存在磁盘并按窗口加载。UI 快照合并不改变音频帧处理数量。CPU/内存上限取决于实机，M0 记录基准，M6 报告实际 RSS、队列高水位、dropout 计数及分析耗时，不编造统一“低于 5% CPU”的结论。

## 发布门槛

影响录音完整性、96 kHz WAV、三种格式、历史表头或恢复的失败属于阻断。纯视觉次要问题可记录限制，但必须可读可操作。缺失硬件验证时交付可以标“开发预览”，不能写“全部验收通过”。
