# 54 · M12 单份参考比较设计

2026-09-17。**参考服务、界面与独立频谱流已接入，当前实现和工程验证见 [55](55-M12-REFERENCE-INTEGRATION.md)。** 下方保留设计与数学口径。外部导入进展见 53，范围保持 38/52，不扩展为编辑器或多参考混音器。

## 来源与范围

ReferenceService 持有主素材 A 和单份参考 B 的来源描述、分析引用、范围与游标/视口/监听增益。外部素材和已保存录音均从 AssetRepository 解析；临时 LIVE 缓存需显式保存后才能成为参考。

从文件库“设为参考”绑定 B；正常打开文件作为 A。A/B 切换不能把 B 再误认为新的 A。重复设置、晚到的源解析、删除/清缓存与后台源变化通过绑定代次淘汰，并等待读取/仪器查询释放；AnalysisService 引用独立计数，不借用播放视图的唯一引用。

A/B 各自可用整段或独立选区；I 从各自范围起点计算，不能拿截至游标 I 冒充选区 I。统计行显示明确范围、格式与状态。完整分析算法/引擎身份不一致时不显示可比的差值。小于 60 秒的 LRA 保留原读数提示，但不计算可判读的 LRA 差值。

## 时间与试听

- 偏移定义为 B 时间 = A 时间 + 偏移。使用整数纳秒/有理数转换至各自采样帧，再四舍五入到最近帧；不能直接复制不同采样率的帧号。
- 默认偏移 0，提供明确的“起点对齐”动作；不自动识别节拍或拉伸声音。映射越出范围时标不可用，不将边界外位置伪装成静音或偷偷夹到边界。
- A/B 试听串行：保存原槽游标/范围/音量，先关闭旧输出，再恢复目标来源及映射后的合法位置。REC 中禁止发声回听；监听增益与统计/频谱数据分离。
- 全部仪器仍显示当前活动 A 或 B 的同一时间上下文；参考面板标明当前活动槽和两份文件名，不另建 FILE/HISTORY 页面。

referenceMath.ts 已提供范围验证、±24 小时纳秒偏移、跨采样率最近帧映射和 A−B 差值。三项单元检查覆盖 44.1/48 kHz、正负偏移、EOF/越界、超过 JS 安全整数的帧号、原始精度、单位与静音/未就绪等状态。I/LRA 差值为 LU，TP 差值为 dB；两份静音不产生伪造的 0 差值。

## 频谱与显示

增加可显隐/停靠的“参考比较”面板，workspace 后续版本迁移保留旧布局并默认隐藏该面板。面板包含 A/B、范围/偏移、统计差值与两条频谱；常态保持紧凑，解释按需显示。

频谱复用 InstrumentService 同一 FFT 窗、平均/保持和声道配置；按 Hz 对齐各自 bin，不改变原采样率。明确统计属于所选范围、频谱属于各自查询游标及平均窗；显示两份素材的真实窗/频率分辨率。单声道与不适用的 Mid/Side/R 状态分别提示。

优先复用活动来源已经计算的仪器包，只补另一份来源，避免同时重复计算 A、B 和主仪器。M8/M9 原生分析总槽仍为两个，参考请求需要容量协调、合并新游标与有界刷新；不能用忽略 QUEUE_FULL 错误冒充通过。大数组使用独立可转移数据流，不能塞入周期性 TraceState 或回复缓存。隐藏参考面板、窗口隐藏或 REC 时停止无用频谱计算，统计引用保留。

两条曲线必须成对标注实际查询位置和绑定身份。慢结果可保留原时间标签并标更新中，不得在新来源/新位置标签下显示旧数据；范围/配置/源变化时失效。

参考接入的冷计算预算在实际压力验证前固定为：最大 FFT/平均窗下，新的双来源频谱请求至成对显示 p95 ≤200 ms；这是两份新位置的计算，不替代原有缓存命中查询 p95 ≤100 ms 和播放呈现偏差门槛。只显示参考面板且活动来源采用选区时，不另外计算无法复用的整文件频谱；需要显示独立主频谱时才保留这项独立计算。全局原生队列两项执行、最多四项等待，前台仪器/瓦片优先，参考请求合并为一个最新待处理位置。

## 实现顺序与验收

1. ReferenceService：来源绑定/代次/独立引用/范围统计，清理等待和源失效；先固定行为再接 UI。
2. 主进程命令：绑定/清除 B、A/B 激活、范围/偏移；播放切换与原有 file.open/seek/selection 生命周期协调。
3. 参考面板、workspace 迁移、频谱数据流及查询资源协调。
4. 真实 WAV/MP3/AAC，不同率/长度/声道、同文件相同范围 0 差值、已知增益差、静音/不足/丢失、随机快速切换、REC 互斥和原文件 hash。
5. M12 完整包/资源/UI 任务通过后，按原八维与权重复评并继续补足短板；当前没有最终分数。
