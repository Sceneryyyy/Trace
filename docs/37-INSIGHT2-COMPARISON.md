## 1. 结论

以“可定制的综合音频测量工作台”为共同目标，本次主观加权评分为：

- **Insight 2：8.5 / 10**
- **Trace preview.9：6.0 / 10**
- **差距：约 2.5 分，主要来自仪器覆盖、布局自由度和测量辅助判断。**

这不是通过率、算法精度百分比、开发完成度或工作量估算。Trace 的原始任务是系统声音录制、缓存回看、响度分析和文件交付；综合分析仪是本次新提出的扩展目标。因此，较低的仪器覆盖分不等于当前录音流程失败。

Insight 值得借鉴的是“按任务组织仪器、把测量结果变成可判断的信息、统一各面板操作”。Trace 值得保留的是统一时间轴、系统录音与缓存保存、文件同位置可重复恢复读数。后续应将这些能力组合成可配置工作台。

## 3. Insight 2 的完整能力地图

### 3.1 Loudness：响度与目标判断

提供 M（400 ms）、S（3 s）、I、Momentary Max、LRA、最大 True Peak；对白门控时增加对白内容占比等显示。

它的价值不只是读数数量：用户可以设置响度目标、TP 上限、LRA 范围，显示会随越界状态改变；支持常用目标预设、绝对/相对刻度，以及不同计量范围。目标线会同步到 History，TP 目标也关联 Levels。

门控有 Off、Program、Dialogue。M/S 始终不做响度门控，不能把界面选择 Dialogue 理解为所有数字都变成对白专属测量。对白门控启动有至少两秒的初始检测等待。

布局随高度自动切换：小于 270 px 的响度面板显示紧凑统计，大于等于 270 px 才显示完整柱表。这是“空间变小后改变信息表达”，而非把完整面板机械缩小。

**重要保存规则：**仪器特定选项随 Layout 和宿主会话保存；响度目标配置随会话保存，独立于 Layout。换工作台布局不会悄悄改掉交付目标。

依据：本地 `loudness/index.html`。

### 3.2 Levels：逐声道电平

提供 True Peak/RMS、峰值保持、RMS 积分时间、刻度和配色设置，支持 Peak+RMS 与 K-System（K-12/14/20）。支持最多 10 声道，包括 7.1.2 配置，并能切换 SMPTE/Film 排序。

7.1.2 支持表示可以接收和显示该声道配置，不据此推断具有完整 Atmos 对象位置、ADM 编辑或空间声学分析功能。

依据：本地 `levels/index.html`、Introduction。

### 3.3 Spectrum：频谱分析仪

频率为横轴、幅度为纵轴；支持连续曲线、1/3 倍频程、整倍频程、临界频带。可设置平均时间、峰值保持、FFT 窗大小、窗函数及重叠比例；鼠标查看位置读数，频率/幅度轴滚轮缩放、拖动平移、双击复位。

适合检查频率能量分布、持续窄带峰值、低频堆积等。时间平均有利于看整体趋势，短平均便于观察瞬时变化。FFT 配置会改变时间/频率分辨能力，不能只用“高精度”笼统命名。

依据：本地 `spectrum/index.html`。

### 3.4 Spectrogram：2D / 3D 声谱图

这两种模式显示频率内容随时间的变化：

- **2D**：平面时间/频率坐标，强弱由颜色或亮度表示，适合找异常发生时刻和持续频带。
- **3D**：增加高度表达幅度，可旋转视角，有 Front/Side/Diagonal 等预设相机位置；可调缩放、高度、历史长度和细节级别。
- 两者共用一组声谱图通用设置，包括 FFT Size、Overlap 和配色。
- 经 Relay 可以同时显示最多 8 个来源，来源可选并指定颜色。

**3D 声谱图的“3D”表示时间、频率和幅度，不能将它理解成声音在房间中的三维位置。** 也不能把 3D 画面的高度误当成响度 LUFS。

视觉判断：3D 适合观察能量随时间的总体形态，也有展示价值；多源曲面可能互相遮挡，透视会压缩轴间距。2D 通常更方便精确定位时间与频率，两种模式应互补。

依据：本地 `spectrogram/index.html` 及 2D/3D 插图。

### 3.5 Sound Field：声像、相位与单声道兼容性

立体声模式有 Polar Sample、Polar Level、Lissajous；配有左右平衡和相关度表。Polar Level 可选择 Peak/RMS/Envelope 检测方式。图形历史通过渐隐/收缩显示；削波样本用红色提示。

环绕声模式显示各声道能量、整体平衡和邻近声道相关度告警。它帮助判断声像偏移、左右相似性和可能的单声道抵消，不能从最终混音直接还原每个声源的真实位置。

相关度接近 +1 表示左右相似；持续负相关提示单声道兼容风险，短暂低于 0 不必直接判为错误。可理解性设计需要同时给数值、方向/范围和说明，不能只有漂亮轨迹。

依据：本地 `sound-field/index.html`。

### 3.6 History：响度历史

提供 M/S/I 三条历史曲线，能独立显示/隐藏，支持时间轴与响度轴缩放、平移、双击复位；悬停读取某时刻的时间和 M/S/I。I 超过目标时，曲线变红。

它以测量计算过程及宿主走带为上下文。全局 Reset/Pause/Hold 各自影响计算重置、保持和冻结。手册没有确认 Trace 式“持久文件逐位置缓存 + 任意重复定位恢复全部表头”的相同契约，因此不把该能力算给 Insight，也不声称实测证明其绝对不能做到。

依据：本地 `history/index.html`、`loudness/index.html`。

### 3.7 Intelligibility：对白可懂度辅助判断

在主总线上放 Insight，在对白总线/轨道末端放 Relay，选择该来源，评估对白在整个混音及低/中/高背景噪声听音环境下的可懂度。显示估计点、推荐区间、10 秒范围历史、源感知响度（phons）及与总输出的差值。

这是估计性、上下文相关的辅助信息，界面本身也称 estimated。它不等于测听众实际听懂了多少内容。与“Dialogue Gate 响度计量”是两件事。

Trace 只有系统总输出时，没有独立对白来源，不能仅加一个名为“可懂度”的表头就提供等价判断。此方向需要独立的来源与算法研究。手册许可章节记录了 Dolby Dialogue Intelligence Technology，不能将相关能力当成 libebur128 的普通开关。

依据：本地 `intelligibility/index.html`、`relay/index.html`、许可目录。

### 3.8 Layouts、全局设置与结果输出

- 顶部仪器选择器控制显示/隐藏；面板分隔线调整尺寸；面板有最大化/恢复，主窗口可缩放至适合少量仪器的大小。官方说明确认显示/隐藏及调整尺寸。[官方界面说明](https://www.izotope.com/community/blog/why-upgrade-to-insight-2?page=54)
- 可保存布局及仪器设置，快速切换预设，恢复未保存的 Working Settings。旧手册图里的预设管理器不完全代表 2.6 当前外观。
- 已确认的是主窗口内的布局管理。没有把“任意拖换排列、无限自由停靠、每个仪器独立浮窗、多屏独立窗口”算成已证实能力。
- 可导出本次计算的 M/S/I 响度 CSV，也能将 I 和响度超标标志送往宿主自动化轨。
- 全局配置包括工具提示、部分持续设置与授权管理。

**明确限制：**手册说明 CSV 一律写绝对响度；即使界面选择 Dialogue Gate，导出的 I 也不反映对白门控值。这会影响“界面截图和数据表是否在说同一件事”的理解，因此结果交付没有给满分。

依据：本地 `layouts/index.html`、`global-options/index.html`。

### 3.9 不归入 Insight 本体的能力

Relay 在 Neutron、Nectar、Tonal Balance Control、Visual Mixer 中还有遮蔽、EQ、混音等联动。阅读了这些说明，但不将其他产品提供的功能合并计入 Insight 得分。Insight 也不是声谱修复编辑器、系统录音机或完整混音器。

## 4. 同一标准评分

评价对象是具备音频基础的使用者，希望在一个窗口看懂电平、响度、频率、声像和历史，并按任务调整仪器。10 分代表该维度非常完整、清楚且适配工作流；8 分表示成熟、有明确改进点；6 分表示主要能力可用但有明显限制；4 分表示仅覆盖共同目标的一部分。

各单项为以 0.5 分为主要粒度的主观评估，不是统计测量。小于 0.5 的差别不宜过度解释。

### 4.1 差距从哪里来

按上述权重，仪器覆盖贡献 1.00 分差距，布局贡献 0.825 分，配置与判读贡献 0.45 分。这三项合计约 2.28 分。其余项差距较小，Trace 的历史定位又追回 0.15 分。

因此优先级应对准仪器底座和布局；只改配色无法消除主要差距。另一方面，6.0 分不是“Trace 只有竞品六成功能”，更不是“还需四成工时”。

## 5. 视觉与易用性：具体学什么

### 5.1 Insight 做得好

1. **仪器语法一致。** 标题、设置、最大化、边框、图内标尺的位置稳定，熟悉一个仪器即可迁移到其他仪器。
2. **常态克制，异常突出。** 大多数底色与曲线中性，颜色用于启用状态、来源区别和越界提醒；符合专业长时间监看的需求。
3. **大小改变时有信息取舍。** 紧凑响度面板保留必要数字，扩大后出现柱表；同一个工具能适应桌角监看和全屏分析。
4. **直接把目标画出来。** 用户看到的不仅是 -23 一类读数，还能看到目标位置、范围及越界结果。
5. **设置跟任务绑定。** 通过布局把常用仪器和参数一起恢复，降低每次开工成本。

### 5.2 Insight 仍有扣分点

- 全开 7 个仪器会很密集；即使可定制，第一次选择哪些仍需要专业知识。
- FFT Size、Overlap、Window、Gate、Hold/Pause 等需要学习。手册有解释，界面仍主要面向熟练用户。
- 某些单位、次要刻度在手册图中偏小偏暗；旧图不能证明本机 2.6 的 HiDPI 有问题，但信息层级仍值得实机验证。
- 多来源的 3D 曲面遮挡、色彩叠加使精确比较变难。
- 数值超限较依赖颜色；可增加更直接的文字/标记辅助。
- CSV 与对白门控显示语义不一致，且本地文档版本/插图落后于安装二进制，理解成本有所增加。
- 没有从手册中获得完整任意时刻持久重建的承诺，不能把“有 History”理解为通用文件检查时间轴。

### 5.3 Trace 具体改进方向

- **压缩顶部结构。** 当前 1264×761 截图中品牌、设备、文件来源三行约占 188 px；可合并次要信息，把空间交给仪器。来源与格式仍应清楚可查。
- **保留绿色品牌，收敛整片绿底。** 背景向中性石墨灰靠拢；绿色用于主要信号/状态，青色用于选区/游标，告警有独立颜色和形状。
- **建立仪器面板统一外壳。** 每个面板具有标题、单位、设置、最大化、隐藏；后续频谱/声场不另造一套控件风格。
- **重做响度面板的信息可选性。** 支持紧凑数字、完整柱表，选择显示 M/S/I 等内容；范围和目标可直接比较。改变显示不改变测量。
- **提升单位和次要标签可读性。** 当前 CSS 多处 9–11 px，TP 单位有 8 px。优先调整最小字号、对比度与间距，不把所有字都做大。
- **帮助按需出现。** 保留用户已经确认的图标走带、滚轮习惯和精简文字；通过悬停、首次使用提示、仪器简短帮助解释，不恢复常驻大段说明。
- **让错误和状态语义统一。** 图内区分未就绪、静音、缺口、历史范围和正在分析；所有新仪器跟随同一来源与游标。
- **文件库/设置进一步分层。** 继续保留折叠详情；当仪器选项增多，分开工作台布局、仪器设置、录音设置和帮助入口。

UI/UX Pro Max 的实时图表检索用于辅助检查图例、状态、暂停/定位和非纯颜色表达。未采用其泛用配色、图库或移动端尺寸规则替换现有桌面产品风格。

## 6. 推荐迭代顺序

以下是后续建议，不是已批准实施的任务或完成承诺。新仪器方向来自用户本次目标，具体边界需在架构阶段确定。

| 阶段 | 主要交付 | 使用者得到什么 | 必要验证 |
| --- | --- | --- | --- |
| A · 可配置仪器工作台 | 显示/隐藏、调尺寸、最大化/恢复、布局保存/恢复/锁定；统一外观 | 录音、响度、频谱等任务使用不同组合，窗口空间可以自己分配 | 隐藏/换布局不重启采集、不结束 REC、不改游标或统计目标；小窗口/DPI/重启布局恢复 |
| B · 频谱与立体声声场 | Spectrum 曲线/峰值保持/平均；相关度、平衡、基础矢量示波 | 分析低频、频率峰、声像偏移和单声道兼容性 | 已知频率/幅度信号、同相/反相/不相关/静音/单声道；实时/缓存/文件一致 |
| C · 2D 声谱图 | 与波形/响度历史共轴；颜色刻度、冻结查看、选区、频率范围 | 在准确时间定位噪声、持续频带、瞬态和尾音 | FFT 窗/跳步时间映射、频率/幅度标定、缺口、长文件分块、seek 代次、资源上限 |
| D · 3D 声谱图 | 复用声谱数据的 3D 显示、相机预设、高度/历史/细节设置 | 更直观地看时频能量形态，并与 2D 互相切换 | 与 2D 同一时刻/频率结果一致；绘图降级不影响采集/写盘；视角复位 |
| E · 目标与报告深化 | 可版本化目标预设、超限事件、测量 CSV/报告、外部文件导入与参考对比 | 判断结果更清楚，能交付给同事复核 | 报告写清来源、范围、门控、算法版本；导出与界面语义一致 |

阶段 E 中简单的目标反馈可以随 A/B 提前实施；复杂报告、导入与参考对比单独分期。先做 2D 再做 3D，是因为二者可以复用时频数据，并且 2D 更便于核对时间/频率位置。3D 仍保留为用户明确想要的能力。

### 6.1 A 阶段建议包含的任务布局

- **录音回看**：波形、响度历史、电平、紧凑响度。
- **响度检查**：完整响度、电平、响度历史、选区统计。
- **频率诊断**：大幅 2D 声谱图、Spectrum、缩小波形。
- **声像检查**：大幅声场、相关度、平衡、电平。
- **自定义**：在以上基础上调整，另存布局；可一键恢复，避免误拖后找不回。

这些均应在同一个窗口完成，不恢复 LIVE/FILE/HISTORY 分页。先明确主窗口内停靠式布局，再决定是否值得做独立浮窗和跨屏；后两项不是本轮已确认的 Insight 能力或 Trace 承诺。

### 6.2 在新增仪器前必须定下的语义

1. 所有仪器读取同一声音来源、epoch/文件标识、时间范围与呈现位置。任何仪器不能因为响应慢而显示另一个时刻却不说明。
2. 隐藏面板不等于停止录音或重新累计响度。显示、分析订阅、历史保存分别定义，避免关闭仪器后出现未说明的数据缺口。
3. 频谱的平均/峰值保持、声场的余辉都有时间窗口。历史定位必须按固定范围重建，不能根据用户来回拖动的顺序累加。
4. 2D/3D 使用共同的时频数据和单位定义；FFT Size、窗函数、hop/overlap、幅度标定会改变分析结果，应进入配置/缓存版本。
5. 未录音 PCM 保持最多 60 秒；新增显示/FFT 缓存有明确预算。长文件分块按需加载；不能把整场高分辨率声谱图堆进内存。
6. 布局、仪器显示参数、测量目标/算法配置分别持久化。切布局不改变交付规范，也不无故失效全部分析缓存。
7. 上游 Prism 的频谱/声场实现先做复用审计和数值验证，再接 Trace 的时间/状态契约；不能因为上游有同名脚本就宣布完成。
8. 3D 降低细节或刷新率只影响绘图；原生采集回调、录音 PCM 完整性和真实响度计算继续独立。

### 6.3 暂缓的扩展

完整多声道/Atmos、独立轨道来源接入、对白可懂度与对白识别、插件间通信需要单独的输入架构与算法验证。当前单/双声道范围继续适用于现有版本。也不由本次视觉参考推导出需要云服务、插件宿主、混音器或完整音频编辑器。
