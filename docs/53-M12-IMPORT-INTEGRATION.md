# 53 · M12 外部素材接入

2026-09-17。ImportService 与组合资产仓库已接入主进程，文件库、文件对话框、拖放、回看、仪器和报告可使用外部素材。当前是 **preview.23 开发构建**；参考比较已接入，当前 preview.24 的验证进展见 55；M12 资源门禁、额外边界和最终八维复评尚未完成。可供稳定回退的完整包仍是 preview.22。

## 已接入的能力

- 音频文件库同屏显示录音与外部素材，搜索/状态/日期筛选适用两者。当前目录明确为“录音目录”；外部缓存和成品另由应用管理，切录音目录保留外部引用及当前外部文件视图。
- 支持 WAV16/24/float32、MP3、AAC-LC M4A/ADTS，单/双声道、8–96 kHz。实际格式来自探测与解码，非仅按扩展名判断；普通视频、多音轨、HE-AAC、多声道与 PCM32 integer 暂不支持。
- 准备队列至多四项，一次解码一项。导入是明确用户动作；录音中可先排队，REC 结束后开始准备。进行中的准备/源读取/后台变更检查可在 REC 或退出时取消。
- 原文件只读；内容变化要求显式“更新素材”，重新定位必须找到相同内容。只变更文件时间且内容一致时不使缓存失效；移除引用不会删除原文件。
- 清缓存先取消并等待读者/消费者释放，再失效元数据并删除已验证的可重建数据。移除引用归档元数据，生成的成品保留，可从“打开素材目录”找回；明确移除生成的成品时验证其归属后移入回收站。
- 每五秒检查外部来源变化，后台检查受 REC/退出取消控制。异步读取和刷新有代次检查，旧结果不能把已清理/移除的资产恢复成 ready。
- 准备完成/失败状态在持久化及清理收尾后发布；取消后再次选择同一文件会重用引用并重新排队，不创建无效重复项。

## 应用与消息边界

AssetRepository 合并录音和导入的窄 ExportRepository；录音生命周期仍属于 RecordingService。file.open、analysis.start、export.describe/start 使用同一来源解析；文件波形、响度、频谱、声场、2D/3D 保留各自实际采样率与源身份。

imports.choose/relocate 通过主进程对话框取得文件。拖放调用 preload 的 [Electron webUtils.getPathForFile](https://www.electronjs.org/docs/latest/api/web-utils)，再通过专用 IPC 接收受文件对象约束的路径；JS 构造的假 File 没有磁盘路径，实际运行已验证被拒绝。renderer 通用命令仅接受资产 ID、操作选项和合法名称，没有任意路径导入命令；专用通道同样验证主窗口/mainFrame。测试路径注入同时受 --trace-test 与测试根目录限制。

报告来源增加 recording/imported 标识，CSV 追加 origin 列；外部文件完整性指文件读取与解码已核验，不宣称曾经的录制过程完整。测量 PCM hash 和媒体身份继续区分，旧 CSV 既有列顺序保持。
