LeoMoon / Trace 声迹 - 同事内测包
软件版本：0.1.0-preview.29
分发修订：InternalTest-r2

一、第一次打开
1. 将整个 ZIP 完整解压到一个可写的本地文件夹。
2. 进入解压后的文件夹，双击 Trace.exe。保留同目录所有文件和 resources 子目录。
3. 无需安装 Node.js、Electron、FFmpeg 或开发工具。
4. 首次升级请先退出旧 Trace；preview.26 及更早版本不能与新版同时运行。
5. 当前优先在 Windows 11 x64、单/双声道系统播放设备上内测。其他系统/硬件请反馈实际结果。

二、录下第一段声音
1. 选择系统正在播放声音的输出设备；需要时点击底部“开始监测”。
2. 点击顶部格式按钮（例如 WAV · 24-bit），选择录音目录和参数。
3. 点击圆形录音图标或按 R 开始；点击方块或按 Escape 结束。
4. 等待处理完成，在“音频文件”中查看并回听。先做一段短录音确认设备和目录。

三、从哪里看说明
- 01-快速上手.pdf：8 页图解手册，建议先读。
- README-Trace.md：更详细的功能说明。
- 02-内测试用清单.txt：建议尝试的任务与结果记录。
- 03-已知限制与版本说明.txt：当前范围和待验证环境。
- 04-问题反馈模板.txt：复制后填写即可。
- 05-许可与来源.txt：软件及依赖来源，原许可文件保留在包内。
