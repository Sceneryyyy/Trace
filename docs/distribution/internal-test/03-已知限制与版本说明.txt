Trace preview.29 / InternalTest-r2

本修订包含一轮界面性能与一致性迭代：实时监测下界面更省电流畅（30 Hz 仪表
不再驱动整界面重绘）、仪表动画改为合成器加速、界面配色令牌统一、窗口跨屏
拖动后图形保持清晰。音频引擎、编码器与功能范围与 preview.28 相同，没有新增
音频功能。快速上手 PDF 沿用 preview.28 版手册，界面外观与操作一致。

当前主要功能
- 系统声音监测、录音、约 60 秒内存历史与显式保存缓存。
- WAV / MP3 / AAC；文件、选区、回听、循环和独立统计。
- 可自定义布局的电平、响度、波形、频谱、声场、2D/3D 与参考比较。
- 外部音频导入、测量目标、HTML/CSV 报告。
- 单实例保护、界面故障恢复入口、有界脱敏诊断与邮件反馈草稿。
- LeoMoon 系列品牌与 TRACE 产品标识。

已知范围与行为
1. Windows x64 开发预览；以单/双声道为范围。当前主要工程验证环境为 Windows 11。
2. 用于系统播放声音采集。DAW 的独占/ASIO 输出不属于已保证的采集范围。
3. 录音中可以看历史；发声回听与系统录音互斥。先结束录音再播放。
4. 未录音的精确声音缓存最多约 60 秒。需要长期保留时显式保存，退出不会自动保存缓存。
5. A/B 配对只在本次运行有效，重启后重新指定；命名布局可持久保存。
6. LRA 短于 60 秒标为暂估，不用于目标或 A/B 差值判断。
7. 不支持普通视频、多音轨、多声道、HE-AAC 和 WAV32 integer 导入。
8. 图形功能不可用时，3D 可降级到 2D。界面大小或显示倍率不修改音频。
9. “上次未正常退出”提示需结合文件实际恢复结果判断，不能直接当作完整性证明。
10. preview.26 及更早版本不遵守单实例锁；使用新版前退出旧版。

仍在收集证据
独立干净 Windows 环境、不同声卡/驱动与物理变化、真实 96 kHz 采集、
混合 DPI 跨屏、普通硬件长时间使用、官方 EBU 原始测试素材专项。
已有开发机隔离配置和自动检查不替代这些验收；本内测包不代表公开测试或测量认证已放行。

数据与更新
- 程序文件夹、当前用户配置、你选择的录音目录相互独立。
- 更新时先正常退出，再将新版本解压到新文件夹，保留旧包方便回退。
- 清理缓存会保留原音频；移除录音/成品需检查确认范围。另存副本独立管理。
- 本包没有自动更新、账号或自动诊断上传，反馈附件由你决定。
