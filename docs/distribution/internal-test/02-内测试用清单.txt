建议先测（约 15-20 分钟，按实际情况调整）
[ ] 完整解压后启动，无需额外安装组件。
[ ] 选择正确输出设备，监测电平随系统声音变化。
[ ] 关闭监测后直接开始录音，结束后可找到、回听该录音。
[ ] 分别试一次 WAV、MP3、AAC，等待处理完成后检查文件可用。
[ ] 未录音时查看最近历史；保存缓存后得到独立文件。
[ ] 点击/拖动历史游标，读数连贯；建立选区、开启循环并回听。
[ ] 清除选区，确认循环关闭；导出时范围与期望相同。
[ ] 通过“编辑布局”移动/调整仪器；完成后重启，排列仍保留。
[ ] 重复启动 Trace，只激活现有窗口，设置与录音不中断。
[ ] 导出一份诊断并打开查看，反馈模板可填写。
