# 41 · M8 频谱与声场数值规范

2026-09-16。起点为 M7 提交 5189f6c / preview.10；本文件先固定 M8.0 的数值与验证口径。M8 功能已接入 preview.11，短门禁通过、长时间资源门禁运行中，当前状态见 42/13；下面保留先于实现确定的数学口径。

## 数据与时间

三种来源最终提供同一只读 PCM 窗口：实际采样率、单/双声道、bufferFirstFrame、frames、requestedFrame、来源/epoch/配置/请求代次。文件通过 WaveSequence/WavReader 分块定位；固定缓存使用 ReplayClip；实时需要新增有界的最近 PCM 窗口复制接口，不能每次 freeze 整个 60s，也不能读波形 min/max 推测 PCM。计算放在工作线程，采集线程不等待 FFT。

第一内核为无状态窗口计算：同一 PCM、位置与配置总是同一结果。最新窗为 [requestedFrame-N, requestedFrame)，较早窗以固定 hop 向前遍历；hop=min(N/4, floor(rate/50))，至少 1 帧。这种锚定不受到达块大小和查询顺序影响。M9 的固定列可以调用同一内核，以该列的实际结束帧作为 requestedFrame。

N 支持 512/1024/2048/4096/8192/16384，默认 2048。平均默认 300ms（0–2000ms），峰值保持默认 1000ms（0–2000ms），声场默认 300ms（50–1000ms）。输入窗口最多 5s；无需整文件驻留。FFT 自身不足 N 帧则 insufficient；平均/保持/声场不足完整范围时附 partial 标记与实际窗口数，不假装已经形成完整统计。缺口和来源失效由上层窗口提供者显式传递，不能混为正常零样本。

## FFT 与幅度

复用上游 DSP::FFT 的复数 forward，新增严格尺寸/参数校验和 Trace 独立窗函数，不复用上游按 push 次数递推的 smoothing。

- 周期 Hann：w[n]=0.5*(1-cos(2*pi*n/N))，求实际 sum(w)。
- 复数 DFT 无预归一化；频率 bin k 对应 k*rate/N，保留 0..N/2。
- 幅度缩放：普通正频率 bin 为 2/sum(w)；DC 与 Nyquist 为 1/sum(w)。
- 内核保存线性幅度平方，界面显示 10*log10(power)，标注 dBFS 幅度谱；不是 PSD，不标 LUFS。
- 左/右各自计算；Mid=(L+R)/2、Side=(L-R)/2 在复数域组合。默认 Stereo 为左右谱功率平均，反相信号不会被相加抵消。
- 单声道 Stereo/Left 使用真实单通道；Right/Mid/Side 不伪装成独立双声道信息。
- 平均先在线性功率域求均值；保持为每个 bin 在固定回看窗口内的最大功率。显示裁切/颜色不改变这些数据。

依据为未归一化 DFT 与窗归一化的明确数学定义：[FFTW DFT 定义](https://www.fftw.org/fftw3_doc/The-1d-Discrete-Fourier-Transform-_0028DFT_0029.html)、[SciPy magnitude 窗归一化说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.ShortTimeFFT.scale_to.html)。它们用于核对数学定义，不新增 FFTW/SciPy 运行时依赖。这里的一侧谱 DC/Nyquist 特例与平均定义是 Trace 明确选择的实现口径。

## 声场

使用固定、截至查询位置的真实样本窗口，双精度累积：

- correlation=sum(L*R)/sqrt(sum(L²)*sum(R²))，零时差、未去 DC 的归一化互相关；夹限 [-1,+1] 只抵御舍入误差。
- balance=(sum(R²)-sum(L²))/(sum(R²)+sum(L²))，-1 为左、+1 为右；此值为功率平衡，不能称为声源空间坐标。
- 无信号时为 silence；只有一边无能量时相关度 insufficient、平衡仍有效；单声道声场为 insufficient，并明确单声道。
- Lissajous 的坐标为 x=(R-L)/2、y=(L+R)/2。正相关趋于竖线，反相趋于横线。
- 最多 2048 个显示点，每个等宽样本桶保留能量最大的真实样本及其帧位置；相关度/平衡仍使用窗口全部样本。点的削波标志来自该点 sample peak，不能称为 true peak。
- Polar 两种视图从同一时间窗的数据推导；检测模式与角度能量聚合在 M8.2 补齐独立用例，不能仅改坐标标签假装实现。
- 非有限 PCM 返回错误；显示不会通过补零掩盖输入损坏。

## 预先固定的数值验收

1. bin 中心正弦：幅度误差 ≤0.01dB；DC/Nyquist 不出现多 6dB。
2. 任意频率、多音和窗边界：选定 bin 与独立双精度直接 DFT 的功率误差 ≤max(1e-8, reference*2e-4)。
3. 同相/反相相关度距离 ±1 ≤1e-9；整周期正交信号 |correlation|≤1e-6；平衡误差 ≤1e-7。
4. 固定种子噪声、静音、单边、单声道、浮点越界但有限、NaN/Infinity，以及 8/44.1/48/88.2/96kHz 组合。
5. 完整窗口与裁出的相同上下文、连续查询与反向/重复查询，结果应逐值一致；缓冲起点/末尾/不足窗不能越界。
6. 平均和峰值保持与直接 DFT 的相同历史窗计算对照，不用 LUFS 或 UI 曲线当参考。
7. 实测最大配置的冷查询耗时；缓存/增量策略依据该结果决定，不能把慢结果或不完整历史默认为成功。

M8.0 的闭合条件是规范、内核参考验证与来源/预算方案。M8.1–M8.4 还要完成原生/IPC、界面、三来源时序、资源和独立包门禁；这些尚未完成。

## 当前实现与测量

InstrumentAnalysis 内核已实现，原生 CTest 14/14 通过；新增内核 3370 个检查点包含逐点几何验证，不等于同数量独立场景。固定种子噪声/多音的直接 DFT、DC/Nyquist、正负相关/正交/单边/单声道、裁出上下文与大帧位置、非有限与越界输入已覆盖。最大配置（96k stereo、FFT 16384、2s 平均/保持）单次冷计算约 39.5ms；此值没有包含读取/IPC/绘图，不作为 p95 达标证明。报告 artifacts/m8/core-latest.json。

## 后续来源与调度方案

- PCM 窗口提供器只复制所需历史范围（最多 5s，实际默认上下文更短），复制后释放源锁；FFT 工作线程不持有采集/录音锁。固定缓存使用 shared_ptr 生命周期，源关闭后未完成任务也不悬空。
- 文件使用 WaveSequence 分块 seek/read；参数路径由主进程的已选资产解析，renderer 只发白名单来源/位置/配置，不发任意路径。
- REC 先按当前原生段帧号和 nativeId/epoch 转换，与纳秒统一时间轴分开；历史临时文件使用冻结缓存自身坐标。
- 最多 2 个待决窗口，普通实时合并为最新待处理请求，seek/来源/配置变更增加代次；旧结果丢弃。原生复制窗口与计算都是有界任务，不会反向阻塞捕获回调。
- 文件呈现将新仪器结果与同一位置的现有表头一起接纳；实时使用同一取样上下文，允许计算延后发布该完整快照。主进程录音状态观察独立持续。不能对每个新实时快照都作废正在计算的任务，造成结果永远无法发布。
- 根据约 39.5ms 的冷计算先测量全链路；默认配置可用更高刷新率，昂贵配置需有界合并或缓存。降低绘图/查询频率不改变 FFT、平均与保持口径。
- 新仪器身份/配置独立于现有 LUFS 缓存；workspace 注册新增 ID 时必须迁移 M7 保存布局，保留用户预设。

来源接口、异步服务、Polar 两种聚合、界面及 A17–A19 全链路尚待 M8.1–M8.4。
