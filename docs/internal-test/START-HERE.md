# Trace 声迹 · Internal Test 1

Windows x64 小范围内测，程序版本 preview.35，测试编号 **IT1**。请先阅读同目录的已知问题。此包未签名，不是正式版；仅测试你有权采集的系统音频。

## 启动前

1. 核对交付目录 `SHA256SUMS.txt` 中程序 ZIP 的 SHA256；PowerShell 可执行 `Get-FileHash -Algorithm SHA256 -LiteralPath '程序 ZIP 的实际路径'`。完整解压 ZIP，运行目录内 `Trace.exe`，保留所有配套文件。
2. 旧版先停止录音，等待导出完成并正常退出；保留旧包和重要录音备份，新包解压到新目录，不覆盖旧版。不同时运行新旧版。
3. 选择独立测试录音目录，避免使用唯一一份重要素材。录音目录用于 Trace 会话；普通 WAV 文件请用“导入”，不要期待普通文件夹自动成为录音。
4. 如果 Windows 提示未知发布者，先核对来源和哈希，按所在组织要求处理；不要为测试关闭防护。无法启动请记录提示并反馈。

## 首次短流程（约 10–15 分钟）

| 步骤 | 操作 | 预期与记录 |
| --- | --- | --- |
| 1 | 启动，选择系统播放设备，播放一段熟悉且有权使用的音频 | 顶部设备与实际选择一致；来源和目标采样率清楚；监测有电平、波形、响度 |
| 2 | 播放约三分钟，开始 WAV24 录音；短暂查看历史后返回实时 | 录音持续；来源状态明确；历史查看不擅自发声；记录有无错误/估算静音提示 |
| 3 | 停止录音，从列表打开，播放/暂停，定位到前中后位置 | 可重开、可听、时间与素材一致；没有爆音、截断或明显缺口 |
| 4 | 从同一录音分别导出 MP3 和 AAC，打开成品回听 | 成品正常完成并可播放；请保留默认原始 WAV，不测试删除唯一来源 |
| 5 | 监测时执行一次“保存缓存”，再打开保存结果 | 新增独立录音，能定位和回听 |
| 6 | 查看频谱低频、2D/3D 声谱和布局；在设置中修改录音格式后取消 | 低频曲线连续，轴/色阶/拾取合理；布局没有遮挡；未应用设置不意外保存 |
| 7 | 正常退出再启动，重新打开录音和成品 | 列表/设置正确恢复；没有无故提示损坏；不对个人原文件做清理 |

每步填“通过 / 失败 / 未执行”，未执行说明原因。听感通过与文件校验是不同证据，请分别记录。成功完成首轮后，再按测试矩阵选择适合自己设备的专项。

## 遇到问题

使用 `FEEDBACK.md` 提交一份可复现记录。先保留原始录音与提示，避免反复覆盖；通过“设置与帮助 → 帮助与诊断”导出诊断，发送前检查是否含不愿分享的信息。无需上传个人录音；可先提供错误文本、截图与最小复现步骤。需要音频时另行确认并使用可分享素材。

若发生文件损坏、丢音或持续无法启动，停止相关步骤并反馈。不要为完成矩阵强制断电、塞满系统盘或关闭系统安全功能。其他硬件项目不适用时填“未执行”。

升级/回退：先正常停止和退出，再使用独立目录的包，保留旧包与测试数据备份；配置迁移/旧版兼容尚未全面验收。macOS 不在本轮支持范围内。
