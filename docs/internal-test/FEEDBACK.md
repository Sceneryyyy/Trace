- CPU / GPU / 内存；屏幕数量与 DPI：
- 采集设备/驱动、真实来源采样率/声道；录音格式/目标采样率：
- 矩阵 ID / 短流程步骤：
- 结果：通过 / 失败 / 未执行（原因）
- 问题标题、期望、实际：
- 从启动开始的最少复现步骤：
- 发生频率（次数/尝试总次数）：
- 是否后台/最小化、切换设备、睡眠、开始/停止录音：
