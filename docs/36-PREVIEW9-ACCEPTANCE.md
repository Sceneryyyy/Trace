- 完整解压 preview.9 软件包后运行 Trace.exe。
- 人工验收前退出旧版本，以免同时操作两个版本。
- 先用可丢弃的测试录音；为文件清理测试准备单独目录。
- “显示与帮助”中核对版本为 0.1.0-preview.9。

## 第一组：日常监测与录音

- [ ] 选择实际使用的系统播放设备，确认来源行的采集格式正确。
- [ ] 关闭监测，直接点击录音；能够开始录音。
- [ ] 停止录音，恢复此前的监测开关状态。
- [ ] 已保存提示可直接打开该录音，文件日期符合本地时间。
- [ ] 录音时查看历史、回到实时，录音持续。
- [ ] 录音超过 60 秒后，概览暗色部分与可回看范围清楚，点击暗色部分不弹无效定位错误。

## 第二组：时间轴和表头

- [ ] 普通滚轮调整 ×1–×4 波形倍率；Ctrl＋滚轮调整 5–60 秒时间窗。
- [ ] 局部放大后，Shift＋滚轮及 Page Up/Down 能横向浏览。
- [ ] 横向浏览保持游标及当前读数，不把移动视野误当成重新定位。
- [ ] 刻度轴、Shift 拖动和选区模式都能建立范围。
- [ ] 右键／Ctrl＋D 清除选区，同时关闭循环并移除选区统计。
- [ ] 空格键与播放按钮行为一致；输入框内不会误触发。
- [ ] 多次返回同一历史位置，数值一致，拖动时不闪空白。
- [ ] 起点、终点、波形复位、跟随游标及循环图标的动作符合预期。
- [ ] 文件格式显示为该资产真实格式，不把 PCM16/24 或压缩文件显示成内部 Float 32。

## 第三组：保存刚才的声音

- [ ] 不启动 REC，监测一段声音后直接点击“保存缓存”。
- [ ] 先建选区再保存，得到对应长度的新录音。
- [ ] 保存时监测保持原状态，当前固定历史仍可查看。
- [ ] WAV、MP3、AAC 各保存一段，成品可独立打开、回听。
- [ ] 新文件从自身起点累计响度，不能拿原监测前缀读数直接比较。
- [ ] 重启后录音仍在，来源、格式、时长和历史正常。

## 第四组：导出与文件管理

- [ ] 导出对话框明确显示来源、整段／选区与时长。
- [ ] 修改参数后关闭重开、重启应用，参数记忆符合预期。
- [ ] 选择“同时另存到指定目录”，完成后能在该目录找到成品。
- [ ] 同名已有文件保留，自动另存使用新名称。
- [ ] 文件列表可搜索、按日期和状态筛选，详情可展开。
- [ ] 重命名不移动或改写音频，重新打开后名称保留。
- [ ] 仅清理缓存后，原始录音和成品仍在，再次查看可以重新准备历史。
- [ ] 外部删除一份“另存副本”不影响 Trace 管理的成品状态。
- [ ] 对可丢弃录音测试移除／清理失效记录，确认范围与回收站结果一致。
- [ ] 切换目录后列表范围明确，切回原目录可找到原文件。
