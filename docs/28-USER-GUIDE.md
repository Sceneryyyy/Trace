# Trace 声迹 · 使用说明

当前版本：0.1.0-preview.28（Windows x64 开发预览）

界面以 LeoMoon 为系列品牌，TRACE 为当前产品名；绿色至青色的狮子月牙标识同时用于顶部和 Windows 图标。

## 启动

完整解压软件包，运行 Trace.exe。保留同目录的 resources、DLL 与编码组件；窗口中的“显示与帮助”可以查看版本和快捷键。

新版使用单实例保护：重复启动会显示已有窗口，不会重新开始录音。首次升级请先退出 preview.26 及更早版本；旧版没有锁协议，不能与新版同时运行。

选择“系统播放设备”。设备旁边显示实际采集格式；打开文件后，文件自己的格式显示在文件标题下。

首次使用可先在录音设置中选择保存目录。设置内提供可用空间和保守的预计可录时长，包含源音频、转码工作文件和分析缓存预算，并预留 512 MiB。

## 导入外部音频

- 打开“音频文件”，点击“导入素材”，或把磁盘文件拖入主窗口。一次最多准备四项；录音中可排队，结束录音后开始准备。准备完成后点击“查看”，沿用同一时间轴、仪器和报告。
- 支持单/双声道、8–96 kHz 的 WAV16/24/float32、MP3、AAC-LC M4A/ADTS。原文件保持只读；分析与解码缓存由 Trace 单独管理。
- 文件变化时点击“更新素材”；移动后用“重新定位”查找相同内容的文件。缺失/失败时，行内会显示可用的准备或定位操作。
- “清理缓存”保留原文件和生成的成品，之后可重新准备。“移除引用”将素材从列表移除，原文件和生成成品继续保留，可通过“打开素材目录”查找。明确移除某个生成成品时，该成品及其缓存移入回收站。
- ADTS 使用实际解码长度，Trace 不猜测原始编辑边界。普通视频、多音轨、HE-AAC、多声道和 WAV32 integer 暂不支持。

## A/B 参考比较

- 正常打开的文件为主素材 A。在文件库点击“设为参考”，或在参考面板使用“当前文件 → B”，指定单份参考 B。临时监测缓存请先保存为文件。
- “参考比较”是可显隐、停靠和最大化的仪器，布局菜单也提供同名预设。A/B 配对属于本次运行；布局会保存，重启后重新选择文件。
- A、B 按钮切换当前工作台来源；正在回听时会先关闭旧输出再继续目标文件。两份文件各自保留监听音量，音量不改变统计或频谱。录音中禁止发声切换。
- 游标联动使用 **B 时间 = A 时间 + 偏移**，按各自实际采样率换算。可明确执行“起点对齐”；越出比较范围时不会偷偷夹到边界，可用“起点”查看对应范围。
- 统计采用各自整段或独立范围，差值方向为 **A − B**；I/LRA 差值为 LU，TP 差值为 dB。短于 60 秒的 LRA 不用于差值判断，静音或未就绪不写假 0。
- 双曲线是各自查询游标的平均功率频谱，使用相同分析设置，按 Hz 对照。底部显示实际查询时间与频率分辨率；平均窗不足会提示。改变视角、显示倍率或监听音量不会修改测量。
- 清理/移除相关素材前会释放比较读取；参考不可用时重新选择。清除参考不会删除任何音频文件。

## 测量目标与报告使用

- 顶部“目标”设置 I 目标/容差、TP 上限，以及可选 M/S 上限、LRA 范围。提供自定义和有版本标识的 EBU 参考预设；修改标准预设数值后转为自定义。
- 响度历史显示 I 目标范围带，× 标记可见曲线中超出目标的点。I 曲线表示截至当时的累计值；完整事件以报告为准。目标只用于比较，不改变音频、响度算法或监听音量。
- 状态条区分整段 I/TP/LRA 和 M/S 当前读数；LRA 短于 60 秒时不用于目标判断。静音、未就绪、缺口和错误不会被当成 0。
- 打开已保存文件，点击走带栏“报告”。选择整段或“选区独立分析”后生成；选区 I 从选区起点重新累计。未保存的最近缓存请先“保存缓存”。
- 报告事件可直接定位时间轴，定位不发声。TP 事件为 10 ms 观察窗口，M/S/I 为 100 ms 快照，不能视为样本级越界时刻。
- 目标改变后，旧报告保留生成时的目标并显示提示；重新生成以应用新目标。可取消或重试，开始录音时后台报告让出处理资源，录音结束后恢复。
- “导出报告”在所选目录新建独立文件夹，包含 report.html、summary.csv、history.csv、events.csv，不嵌入音频。HTML 与 CSV 都保留范围、状态和来源标识；CSV 为原始精度，计量 PCM hash 与媒体身份分别记录。
- 生成的预览是临时文件，最多保留八份，重启或清理相关缓存会清理。需要长期保存时使用“导出报告”；已导出的报告与原音频不会随缓存清理删除。

## 自定义仪器工作台操作

- “仪器”选择要显示的电平、波形、响度历史、响度、频谱、声场和声谱图；全部隐藏时仍可恢复。
- 每个标题栏可打开仪器设置、最大化/恢复或隐藏。响度支持紧凑数字与完整柱表，历史可独立显示 M/S/I。
- 点击顶部“编辑布局”。编辑时显示操作提示、标题拖动把手和分隔线手柄；拖动标题到另一个面板边缘停靠，也可在仪器设置的“移动仪器”中选择目标及方向。点击“完成布局”结束编辑并锁定位置与大小。
- 拖动分隔线调整尺寸；分隔线获得键盘焦点后，方向键也能调整，Home/End 到达比例边界。
- 布局菜单提供“录音回看”“响度检查”，支持另存自定义布局、更新、重命名和删除；恢复默认保留自定义预设。
- 调整布局不会改变录音、监测、来源、游标或选区。布局设置自动保存；下拉框中的“自定义布局”表示当前排列未绑定命名预设，不代表保存失败。需要命名并随时切换时，点击下拉框右侧“保存与管理布局”，输入名称并“另存新布局”。录音参数和响度目标独立保留。
- 窗口或自定义区域太小时，面板按最小可读尺寸保留；可调整布局或最大化单个仪器。

## 频谱与声场

从布局菜单选择“频率与声像”，或在“仪器”中显示频谱与声场。

- 频谱显示当前、平均和固定时间峰值保持；点击图例可以分别显隐。滚轮缩放频率，Ctrl＋滚轮缩放电平；拖动坐标轴平移，双击或“复位”还原坐标。
- 仪器设置可调整 FFT 窗、平均/保持时间及声道；默认“声道能量”在双声道时使用两声道谱功率平均。Mid/Side 需要双声道。
- 声场包含示波、极坐标采样和能量视图；能量可用 RMS、Peak 或包络检测。显示倍率只放大图形，不改变相关度和平衡。
- 相关度持续低于零可能提示单声道相消；功率平衡 −1 为左、+1 为右。单声道、静音、数据不足和缺口分别显示。
- 拖动波形历史时，新仪器随同一游标更新；平均、保持、余辉来自固定音频窗口，重复回看不会再累计。
- 改变影响分析的参数时重新查询；布局、配色和显示倍率不改变音频或录音。

## 2D 声谱图

从布局菜单选择“时频检查”，也可以单独打开“声谱图”仪器。

- 横轴与波形、响度历史共用时间范围；纵轴为频率，颜色表示 dBFS 幅度。色阶范围显示在上方。
- 点击或拖动定位共用游标；Shift 拖动或拖动时间刻度建立选区。Ctrl＋滚轮缩放时间，Shift＋滚轮平移文件时间范围。
- 普通滚轮缩放频率；“复位”恢复频率和色阶。设置内可选择 FFT 窗、声道和配色，独立于频谱曲线设置。
- 悬停显示实际 FFT 窗结束时刻、原始频点频率和幅度。色块可能汇总多个频点/时间窗，其最亮颜色不等于悬停原始频点的值。
- 斜纹表示未覆盖或缺口。音频开始处尚不够一个 FFT 窗、超出实时缓存以及尚未分析的部分都不会显示成正常信号。静音有有效覆盖，频点读数显示 −∞。
- 录音中只对当前段仍保留的 PCM 建立精确声谱图；查看较早的完整历史，需要结束录音后打开文件。关闭文件会释放相关查询。
- 单声道素材若沿用 Mid/Side/右声道设置，会说明需要双声道，并可一键切回默认声道；读取失败时可点击“重试”。
- 可在同一仪器内切换 2D / 3D；两者共用来源、时间范围和原始点读数。
- 3D 中拖动旋转、滚轮缩放视角；正面/侧面/斜视/俯视与“视角复位”用于恢复常用相机。高度和细节仅改变显示。
- 3D 底部刻度仍是共用时间轴，可拖动建立选区。悬停表面查询原始频点，不能把 3D 高度理解成 LUFS 或声源空间位置。
- 图形设备不可用时会说明原因并显示 2D，采集/录音继续；可恢复图形或点击“重试 3D”。
- 目标报告和外部素材参考比较仍按后续阶段推进。

## 监测与录音

- “开始／停止监测”控制系统声音采集。
- 圆形录音图标或 R 开始写盘；即使监测关闭，也能直接开始录音。
- 录音图标变为方块；点击方块或按 Escape 结束录音。
- 停止后按原先的监测开关意图恢复。正常录音结束会出现简短提示，可直接查看录音或打开目录。
- 录音中可以查看历史。声音回听与系统录音互斥。
- “实时”回到最新位置；监测关闭时也可用它开始监测。

WAV 支持 16/24-bit PCM、32-bit float，采样率跟随来源或选择 44.1/48/88.2/96 kHz。MP3/AAC 使用 44.1/48 kHz 和码率选项；AAC 支持 M4A 与 ADTS。

需要重采样或压缩时，停止后生成独立成品。保留原始 WAV 默认开启；关闭后仅在成品和分析核验完成后处理源文件。WAV 直录的唯一成品始终保留。

## 一个时间轴完成实时与历史查看

波形、响度历史和表头共用当前位置：

- 图内点击或拖动：定位历史，松开后保持位置。
- 刻度轴拖动、Shift＋图内拖动，或“选区”模式：建立选区。
- 拖动选区两端：调整范围；选区的 I/LRA/MAX TP 单独计算。
- 右键“清除选区”或 Ctrl＋D：同时清除选区、循环与独立统计。
- 循环图标：开启／关闭选区循环。先建立选区再开启。
- 跟随游标图标：画面随播放位置移动。
- 波形复位图标：恢复当前来源的完整时间范围。

时间窗为 5–60 秒连续缩放。完整文件／全长概览可以大于 60 秒。

| 操作 | 方式 |
| --- | --- |
| 时间缩放 | 波形区 Ctrl＋滚轮 |
| 波形显示倍率 ×1–×4 | 波形区滚轮 |
| 横向浏览文件／固定缓存 | Shift＋滚轮 |
| 向前／向后移动一屏 | Page Up／Page Down |
| 播放／暂停 | Space |
| 起点／终点 | Home／End |

输入框、下拉框和对话框拥有键盘焦点时，全局走带快捷键不会抢占输入。显示倍率只改变画图；回听音量只改变输出，不改变测量和导出音量。

实时精确历史在内存中最多保留约 60 秒。查看时固定一份缓存，后台采集继续。录音全长概览的暗色部分不能精确回看，结束后打开文件可查看完整历史。边界来自实际已发布音频帧。

只有发声回听会暂停系统采集，避免回听声音再被自身录入；暂停、定位或播放结束后恢复原监测意图，并保持当前历史视图。

## 保存刚才的缓存

未开启录音也可以保存刚才的声音：

1. 在实时页点击“保存缓存”，保存最近可用缓存；也可以先拖动历史、建立选区。
2. 存在选区时保存选区，否则保存整份固定缓存。
3. 使用当前录音设置生成新的独立录音，支持 WAV、MP3、AAC。
4. 完成后可从提示直接查看；源文件及最终成品各自重新分析。

保存后的文件从自身起点重新累计 I；它与原监测起点到游标的累计读数可能不同。缓存保存不会启动 REC 或重启健康监测。平时监测不生成音频临时文件，只有显式保存时才写入新文件。

若保存未完整完成，已写入内容保留在录音列表，可按提示恢复。不要把未知尾部当成已经保存。

## 导出与另存

文件／选区点击“导出”：

- 显示当前来源、整段／选区与时长。
- 首次 WAV 导出跟随来源格式；最近使用的参数会记忆。
- 开启“同时另存到指定目录”，可在开始时选择交付目录，完成后自动另存。
- 已有同名文件不会被覆盖；自动交付选择新的名称。
- 录音优先，必要时暂停另存，结束后继续。
- 退出或异常中断的另存不会在重启后静默重试，可从文件详情重新另存。

Trace 管理的成品与“另存副本”分别管理。删除外部副本不会删除 Trace 内的成品；文件详情中的“另存位置”打开完成交付的目录。

ADTS 在其他播放器中可能呈现首尾填充；一般回听建议使用 M4A。Trace 记录 ADTS 的有效范围。

## 管理录音文件

列表显示当前保存目录中的 Trace 录音。切换目录保留原目录的文件，当前列表随目录切换。

- 默认每条录音显示名称、日期、时长、格式和状态；“查看”“导出”直接可用。
- 可搜索名称、按本地日期和状态筛选；超过 50 条分页展示。
- 展开“文件与分析详情”，管理原始文件、分段、成品、分析任务。
- 支持重命名，名称和默认文件日期使用本地时间；内部时间记录保留 UTC。
- 显示音频及缓存的文件大小合计；“仅清理缓存”保留原始录音和成品。
- 成品文件缺失或被修改时，对应解码音频会保留，避免清掉可能仅剩的副本。
- “移除录音／成品”明确确认范围并移至回收站。
- “清理失效记录”处理目录已不存在的录音和全部成品文件已不存在的导出；不完整但仍有可用音频的录音保留供检查。

分析取消或失败时，画布显示真实状态。“继续分析／重新分析”保留当前游标、选区和窗口。文件被外部移动或删除后，可刷新状态并检查详情。

## 数值与问题处理

- Peak/RMS：dBFS；TP/MAX TP：dBTP。
- M：400 ms；S：3 s；I：当前说明所指的累计范围。
- 文件视图大号 I 为截至游标的累计 I；另有整段 I。文件 LRA/MAX TP 默认为整段统计。
- 时长不足 60 秒的 LRA 标为暂估。
- “—”表示未就绪或不可用，“−∞”表示静音，不把设备故障当静音。

异常提示提供重新连接、重新分析、重试回听或查看文件等入口。“显示与帮助 → 诊断与反馈”提供导出诊断、复制诊断和邮件反馈。

- 导出会在所选目录中新建独立文件夹，包含 diagnostics.json 和 feedback.txt，不覆盖已有文件。
- 诊断包含版本/构建、系统与图形功能状态、近期故障和当前任务状态；不包含音频、文件名、个人路径或设备身份。日志最多保留 128 条固定字段记录。
- “邮件反馈”打开收件人为 472841772@qq.com 的邮件草稿；请检查正文并手动添加诊断附件，软件不会自动发送邮件。没有邮件客户端时，可以导出诊断后通过网页邮箱发送。
- 界面异常时可恢复界面、导出诊断或结束并退出；界面恢复不重新启动录音。主进程发生致命异常时退出，重启后提示检查音频文件及恢复状态。
- “上次未正常退出”不代表录音必然丢失或完整；请在音频文件列表查看实际恢复结果。本地日志目录不可写时仍可尝试导出当前状态。

“显示与帮助”中可设置录音中关闭窗口前确认。正常退出会完成已经写入部分的收尾。

设置文件短暂被占用时会自动重试，录音与操作继续。如果始终无法写入，顶部会显示“设置未保存”和“重试保存”；上次完整配置保留。
