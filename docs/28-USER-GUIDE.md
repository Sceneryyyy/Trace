# Trace 声迹 · 开发预览使用与验收指南

版本：0.1.0-preview.8 · Windows x64 · 2026-09-16

## 启动

解压完整的 Trace ZIP，双击同目录下的 Trace.exe。请保留整个目录，包括 resources、DLL 和语言资源；单独复制 EXE 无法运行。无需启动开发工具，也无需另装 FFmpeg。

本包是未签名的内部开发预览，不是已完成全部硬件与标准素材验收的正式发布版。程序只在本机处理音频，不含账号、云同步、VST 或 TUI 安装。

首次打开后，Trace 选择可用的默认系统播放设备并进入 实时；之后会记住监测开关。声音来源下拉框用于选择要记录的 Windows 播放设备。请让音乐、浏览器或 DAW 的声音实际送到此设备的 Windows 音频端点；首版不保证捕获 DAW 的 ASIO 独占输出。

## 先做一次录音

1. 播放一段声音，检查 实时 的电平、响度和滚动波形。实时 未录音时不保存音频。
2. 点击来源栏中的保存格式摘要，选择 WAV / MP3 / AAC、采样率、精度或码率及保存目录。
3. 保持“保留原始 WAV”开启，便于首轮验收核对源文件。
4. 点击圆形录音图标或按 R；录音时图标变为方块，点击它或按 Escape 结束录音。即使监测已关闭，也能直接开始录音；结束后恢复原来的监测选择。
5. MP3/AAC 或需重采样的 WAV 在停止后继续生成成品。等待文件列表显示就绪，再回听成品。

WAV 默认跟随来源、24-bit PCM；也支持 16-bit PCM 与 32-bit float。跟随来源时采用设备真实采样率。MP3/AAC 输出为 44.1 或 48 kHz，使用码率设置。AAC 默认 M4A，另支持 ADTS .aac。

关闭“保留原始 WAV”后，Trace 只在独立成品及其分析核验完成、原始文件身份仍匹配且没有占用时整理原始文件；存在失败时保留源文件并提示。WAV 直录的唯一最终文件始终保留。成品和文件历史缓存仍占用磁盘空间。

## 同一工作台中的 实时 与历史

无需开始录音。Trace 在原生内存保留最近最多约 60 秒的连续音频及计量历史。在波形或响度图中点击、拖动游标即可查看过去的数据；松开后保持当前位置。图形、表头和走带控制始终在同一个工作台。点击时间轴左侧 实时 回到最新采集位置。

查看历史会固定当前缓存快照，后台继续采集和录音；拖动本身不发声。只有点击“播放”才暂停采集，避免把自身回听声音收进缓存；暂停、拖动游标或播放结束后，按原先的监测开关恢复采集，历史游标保留。点击 实时 则明确返回实时监测；健康采集不会重启。录音期间可查看历史，需结束录音后才能发声回听。切换设备、重置统计或出现数据缺口会重建实时缓存；已有历史快照保持不变。临时缓存不创建音频文件、不提供导出，退出应用即丢失。

48 kHz 双声道 60 秒的 float32 PCM 约 22 MiB，96 kHz 约 44 MiB；冻结回听还占用快照和有界计量数据；切换时未完成的选区分析可能短暂持有上一份快照。

## 读数来源

| 来源 | 读数含义 | 时间轴 |
| --- | --- | --- |
| 实时 | 本轮系统声音监测 | 连续 5–60 秒 |
| REC | 当前连续录音段自己的计量历史 | 全长概览，最近约 60 秒可精确定位；浏览不停止录音 |
| 临时历史 | 缓存中当时的电平、M/S/I/LRA/TP | 固定快照，定位、选区和回听 |
| FILE | 所选原始文件、成品或导出的独立历史 | 点击/拖动定位，两图共享游标、选区与缩放 |

这些是数据来源，不是需要切换的页面。REC 全长概览保留；精确缓存只覆盖当前连续段最近约 60 秒，超出范围会明确提示。结束录音后打开保存文件，可查看完整历史。临时历史的 I/LRA/Max TP 来自当时的监测或录音段累计值；选区统计从选区起点独立计算。

“—”表示未就绪或不可用；“−∞”表示已确认静音。LRA 在短于 60 秒的文件/录音中标注暂估。目标线与波形显示倍率只改变显示，不调整音量或测量结果。

## 走带控制

底部走带从左到右为：起点、终点、播放/暂停、录音/结束录音。图标悬停显示功能与快捷键。“实时”按钮位于“开始/停止监测”左侧，用于回到最新采集位置。起点、终点定位当前文件或已固定缓存的边界，并保持暂停；录音中查看历史边界不会结束录音。无已选历史/文件时，边界按钮禁用。

## 回听、选区与导出

在“录音文件”中点击具体资产的“查看”，文件会载入同一时间轴。查看文件不停止后台采集，也不要求输出设备可用；按“播放”后才开始发声。

- 点击波形或响度历史定位；播放时拖动会暂停回听，松开后停在所选位置，再按播放继续。定位读取期间保留上一组完整读数，新数据就绪后与游标一同更新；不会为追求平滑改变响度数值。
- 鼠标在波形区域时，Ctrl + 滚轮连续调整 5–60 秒时间窗，普通滚轮调整 ×1–×4 波形显示倍率。波形与响度图的时间轴一起变化。
- 缩放滑杆位于波形上方、定位/选区按钮右侧；“波形复位”图标恢复整个文件或当前缓存的时间范围。短于 5 秒时按实际长度显示；滚轮缩放范围不改变选区边界、回听音量或保存音频。
- 主动浏览关闭“跟随游标”，重新开启即可跟随播放头。
- 在两图中间的时间刻度轴上直接拖动选择范围；也可点击“选区”模式后在图内拖动，或使用 Shift 拖动。
- 拖动选区两端调整边界。时间轴栏提供“波形复位”“跟随游标”“循环”三个图标按钮，悬停显示功能说明；跟随与循环开启时高亮。
- 建立选区后点击“循环”按钮，再点击“播放”或按 Space；再次点击“循环”关闭循环。开启时按钮高亮。
- 文件历史 I 不因重复播放累计。
- 下方“选区独立统计”从选区起点计算，区别于右侧文件起点累计 I。
- 点击“导出”，选择整个文件或当前选区以及目标格式。成品有独立回听和分析入口。
- “另存”将成品复制到选定位置，不覆盖同名文件；“打开目录”便于查看会话文件。

首版仅重开 Trace 本机录制的会话，不提供任意外部音频导入或剪辑编辑器。

## 文件列表管理

打开“录音文件”会核对磁盘文件；列表打开期间定时刷新，切回窗口也会刷新，可手动点击“刷新文件状态”。外部删除或移动后显示文件不可用，禁用该资产的回听、分析与另存；文件放回原位置后可恢复。

- 搜索录音名称；较长列表分批显示。
- “移除成品”只将对应成品及其回听缓存移至系统回收站，保留原始录音。
- “移除录音”将整个录音会话、全部成品与缓存一起移至回收站；会先关闭该会话的回听。
- 两种移除都有范围说明，默认“取消”。录音或导出处理期间不能执行。
- 磁盘目录已不存在时，只清理失效记录，不重新创建目录。

“另存副本”是在其他位置复制一份成品。删除那份副本不会删除 Trace 内部成品，列表继续保留是正常的；“打开目录”显示 Trace 实际管理的位置。

## 快捷键与显示

| 操作 | 快捷键 |
| --- | --- |
| 开始录音 | R |
| 结束录音 / FILE 暂停 | Escape |
| 已选历史 / 文件播放、暂停 | Space |
| 当前文件 / 历史回到起点、终点 | Home / End |
| 建立选区 | 刻度轴直接拖动，或 Shift + 图内拖动 |
| 时间缩放 | 波形区 Ctrl + 滚轮 |
| 波形倍率 | 波形区滚轮 |

编辑控件内不触发 R / Space / Home / End；Escape 仍可停止录音或暂停回听，设置对话框内则优先关闭对话框。顶部“显示与帮助”可设置响度目标线和波形倍率。窗口位置、尺寸、保存设置、连续缩放值与监测开关会在下次打开时恢复。旧版 ×16 显示偏好会迁移为 ×4，目标线设置保留。

## 建议人工验收顺序

请记录设备名称、Windows 设备格式、Trace 版本和出问题的操作；录音及截图自行选择可分享的内容。

- [ ] 在当前常用设备播放、静音、恢复；实时 电平与声音一致。
- [ ] WAV 录制后回听，起止、左右声道、静音长度正确。
- [ ] MP3、AAC-M4A、AAC-ADTS 各录一段，成品就绪后回听。
- [ ] FILE 点击几个固定位置，暂停再回到相同位置，读数重复一致。
- [ ] 选区循环、选区独立统计和选区导出结果符合预期。
- [ ] REC 中浏览/缩放历史、最小化后恢复，录音持续并可正常结束。
- [ ] 检查最小窗口、两台显示器以及你实际使用的 Windows DPI 设置。
- [ ] 退出重开，文件列表与设置恢复；断网仍能回听和导出。
- [ ] 若设备支持，亲自将设备配置为 96 kHz，再检查跟随来源 WAV 的真实格式。
- [ ] 用可丢弃的测试录音检查声卡/DAW 切换或设备断开时的提示与恢复。

## 已知验证范围

已完成真实 WASAPI 监测、一次 30 分钟录音、格式/帧数/恢复/文件历史工程检查，以及独立包在新用户数据目录、精简 PATH、空工作目录和模拟断网条件下的完整流程。

六组尺寸/缩放使用 1024×700、1280×800 窗口目标及 100/150/200% 进程/渲染缩放；双显示器的位置和重启恢复另行实测。本机两台显示器的 Windows 实际缩放都是 100%，混合系统 DPI 的跨屏动态切换仍待人工验证。

仍未通过：原始 EBU 官方节目素材门禁、真实捕获 96 kHz、物理拔插/驱动改格式全矩阵，以及独立干净 Windows/VM 环境。生成参考信号和隔离配置测试不替代这些项目。

出现“录音未完整完成”时，先保留整个会话目录。文件列表的恢复入口可恢复已完整写入的部分；未知缺口和未写入的尾部不会被伪造补齐。
