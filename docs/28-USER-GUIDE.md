# Trace 声迹 · 使用说明

当前版本：0.1.0-preview.10（Windows x64 开发预览）

## 启动

完整解压软件包，运行 Trace.exe。保留同目录的 resources、DLL 与编码组件；窗口中的“显示与帮助”可以查看版本和快捷键。

选择“系统播放设备”。设备旁边显示实际采集格式；打开文件后，文件自己的格式显示在文件标题下。

首次使用可先在录音设置中选择保存目录。设置内提供可用空间和保守的预计可录时长，包含源音频、转码工作文件和分析缓存预算，并预留 512 MiB。

## 自定义仪器工作台

- “仪器”选择要显示的电平、波形、响度历史和响度；全部隐藏时仍可恢复。
- 每个标题栏可打开仪器设置、最大化/恢复或隐藏。响度支持紧凑数字与完整柱表，历史可独立显示 M/S/I。
- 点击“已锁定”进入编辑布局。拖动标题到另一个面板边缘停靠；也可在仪器设置的“移动仪器”中选择目标及方向。
- 拖动分隔线调整尺寸；分隔线获得键盘焦点后，方向键也能调整，Home/End 到达比例边界。
- 布局菜单提供“录音回看”“响度检查”，支持另存自定义布局、更新、重命名和删除；恢复默认保留自定义预设。
- 调整布局不会改变录音、监测、来源、游标或选区。布局设置自动保存；录音参数和响度目标独立保留。
- 窗口或自定义区域太小时，面板按最小可读尺寸保留；可调整布局或最大化单个仪器。

## 监测与录音

- “开始／停止监测”控制系统声音采集。
- 圆形录音图标或 R 开始写盘；即使监测关闭，也能直接开始录音。
- 录音图标变为方块；点击方块或按 Escape 结束录音。
- 停止后按原先的监测开关意图恢复。正常录音结束会出现简短提示，可直接查看录音或打开目录。
- 录音中可以查看历史。声音回听与系统录音互斥。
- “实时”回到最新位置；监测关闭时也可用它开始监测。

WAV 支持 16/24-bit PCM、32-bit float，采样率跟随来源或选择 44.1/48/88.2/96 kHz。MP3/AAC 使用 44.1/48 kHz 和码率选项；AAC 支持 M4A 与 ADTS。

需要重采样或压缩时，停止后生成独立成品。保留原始 WAV 默认开启；关闭后仅在成品和分析核验完成后处理源文件。WAV 直录的唯一成品始终保留。

## 一个时间轴完成实时与历史查看

波形、响度历史和表头共用当前位置：

- 图内点击或拖动：定位历史，松开后保持位置。
- 刻度轴拖动、Shift＋图内拖动，或“选区”模式：建立选区。
- 拖动选区两端：调整范围；选区的 I/LRA/MAX TP 单独计算。
- 右键“清除选区”或 Ctrl＋D：同时清除选区、循环与独立统计。
- 循环图标：开启／关闭选区循环。先建立选区再开启。
- 跟随游标图标：画面随播放位置移动。
- 波形复位图标：恢复当前来源的完整时间范围。

时间窗为 5–60 秒连续缩放。完整文件／全长概览可以大于 60 秒。

| 操作 | 方式 |
| --- | --- |
| 时间缩放 | 波形区 Ctrl＋滚轮 |
| 波形显示倍率 ×1–×4 | 波形区滚轮 |
| 横向浏览文件／固定缓存 | Shift＋滚轮 |
| 向前／向后移动一屏 | Page Up／Page Down |
| 播放／暂停 | Space |
| 起点／终点 | Home／End |

输入框、下拉框和对话框拥有键盘焦点时，全局走带快捷键不会抢占输入。显示倍率只改变画图；回听音量只改变输出，不改变测量和导出音量。

实时精确历史在内存中最多保留约 60 秒。查看时固定一份缓存，后台采集继续。录音全长概览的暗色部分不能精确回看，结束后打开文件可查看完整历史。边界来自实际已发布音频帧。

只有发声回听会暂停系统采集，避免回听声音再被自身录入；暂停、定位或播放结束后恢复原监测意图，并保持当前历史视图。

## 保存刚才的缓存

未开启录音也可以保存刚才的声音：

1. 在实时页点击“保存缓存”，保存最近可用缓存；也可以先拖动历史、建立选区。
2. 存在选区时保存选区，否则保存整份固定缓存。
3. 使用当前录音设置生成新的独立录音，支持 WAV、MP3、AAC。
4. 完成后可从提示直接查看；源文件及最终成品各自重新分析。

保存后的文件从自身起点重新累计 I；它与原监测起点到游标的累计读数可能不同。缓存保存不会启动 REC 或重启健康监测。平时监测不生成音频临时文件，只有显式保存时才写入新文件。

若保存未完整完成，已写入内容保留在录音列表，可按提示恢复。不要把未知尾部当成已经保存。

## 导出与另存

文件／选区点击“导出”：

- 显示当前来源、整段／选区与时长。
- 首次 WAV 导出跟随来源格式；最近使用的参数会记忆。
- 开启“同时另存到指定目录”，可在开始时选择交付目录，完成后自动另存。
- 已有同名文件不会被覆盖；自动交付选择新的名称。
- 录音优先，必要时暂停另存，结束后继续。
- 退出或异常中断的另存不会在重启后静默重试，可从文件详情重新另存。

Trace 管理的成品与“另存副本”分别管理。删除外部副本不会删除 Trace 内的成品；文件详情中的“另存位置”打开完成交付的目录。

ADTS 在其他播放器中可能呈现首尾填充；一般回听建议使用 M4A。Trace 记录 ADTS 的有效范围。

## 管理录音文件

列表显示当前保存目录中的 Trace 录音。切换目录保留原目录的文件，当前列表随目录切换。

- 默认每条录音显示名称、日期、时长、格式和状态；“查看”“导出”直接可用。
- 可搜索名称、按本地日期和状态筛选；超过 50 条分页展示。
- 展开“文件与分析详情”，管理原始文件、分段、成品、分析任务。
- 支持重命名，名称和默认文件日期使用本地时间；内部时间记录保留 UTC。
- 显示音频及缓存的文件大小合计；“仅清理缓存”保留原始录音和成品。
- 成品文件缺失或被修改时，对应解码音频会保留，避免清掉可能仅剩的副本。
- “移除录音／成品”明确确认范围并移至回收站。
- “清理失效记录”处理目录已不存在的录音和全部成品文件已不存在的导出；不完整但仍有可用音频的录音保留供检查。

分析取消或失败时，画布显示真实状态。“继续分析／重新分析”保留当前游标、选区和窗口。文件被外部移动或删除后，可刷新状态并检查详情。

## 数值与问题处理

- Peak/RMS：dBFS；TP/MAX TP：dBTP。
- M：400 ms；S：3 s；I：当前说明所指的累计范围。
- 文件视图大号 I 为截至游标的累计 I；另有整段 I。文件 LRA/MAX TP 默认为整段统计。
- 时长不足 60 秒的 LRA 标为暂估。
- “—”表示未就绪或不可用，“−∞”表示静音，不把设备故障当静音。

异常提示提供重新连接、重新分析、重试回听或查看文件等入口。“复制诊断”以及帮助中的“复制诊断信息”只复制固定状态字段，不含个人路径、录音名称、设备标识或 PCM。

“显示与帮助”中可设置录音中关闭窗口前确认。正常退出会完成已经写入部分的收尾。
