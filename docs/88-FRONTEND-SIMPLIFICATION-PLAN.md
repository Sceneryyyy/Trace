## 1 · 目标与范围

把 preview.34 列表采用的“主操作突出、低频管理收起、选择与发声分开、状态随上下文呈现”推广到整个工作台。主要目标：

1. 打开应用后，能快速辨认当前查看的来源、采集/录音状态和主要操作。
2. 常用查看、回听、录音、选区与导出保持直接可达；管理按钮和高级参数减少常驻。
3. 文件版本、测量范围、质量和异常仍明确，避免只精简画面却增加误操作。
4. 使用现有仪器工作台、模态容器、列表侧栏和命令，不新增顶层业务页面或第二套走带。

本版本建议包含 UI88-00～09 的云端可完成内容；Windows 视觉、听感、设备及原生对话框验收独立列出。本文的 P1/P2 只用于本方案排期，不重开 83/84 已完成的 P0/P1，不覆盖 [76](76-RELEASE-CHECKLIST.md) 的发布门禁。

不纳入：自动连播、自定义歌单、拖动排序、批量处理、多轨编辑、效果器/VST、云同步、账号、新音频格式、多声道扩展、macOS 后端，以及新计量算法、缓存格式或后台任务系统。

以下属于不同语义，不能合并成一个模糊按钮或数值：

- **实时**：回到最新采集位置；**开始/停止监测**：改变监测意图；**REC**：开启/结束录音写盘。浏览历史仍可采集，不能把“当前看文件”当成“已停监测”。
- **选择文件**、**查看分析**、**显式回听**各有独立行为。查看不发声，当前回听项暂停/继续不重新打开来源。
- **截至游标 I、整段 I、选区统计、A/B 范围统计**有不同范围；精简呈现仍保留名称和单位，不能直接用同一个值替换。
- **查看分析**可复用缓存，**重新检查/准备素材**会启动工作；两者可分层，不可删去修复旧缓存/来源变化的能力。
- **另存副本、移除成品、移除录音、移除外部引用、仅清理缓存**有不同文件后果，必须保持原有保护及确认。
- **复位时间范围、复位频率/色阶、复位相机**互不等价；通过命名和所属菜单区分。

## 4 · 建议界面结构与操作迁移

### 4.1 工作台结构

```text
品牌与状态：LeoMoon / TRACE │ 采集、REC 与故障状态 │ 目标 │ 设置与帮助
工作上下文：当前来源/版本 │ 设备与录音设置摘要 │ 时间轴工具 │ 布局
主要画布：已有可配置仪器工作台                       │ 音频文件侧栏
走带：起止定位、播放/暂停、REC │ 实时、监测 │ 主时间码 │ 音量、导出、报告、文件
```

这是信息组织示意，不是固定像素稿。设备与录音设置合入工作上下文的紧凑入口，不在文件模式保留完整设备配置行。1400 CSS px 侧栏阈值与 420 px 宽度沿用 87；本轮不同时修改布局存储树和侧栏停靠机制。

全局品牌/状态栏、上下文工具栏与底部走带职责分开。普通状态不新增独立全宽工具行；目标启用与错误发生时可以出现必要的摘要/警示。布局内部的局部刻度、图例和参数不按全局工具条计算。

在原窗口和同窗口列表内完成操作，不新建 LIVE、FILE、报告等顶层页面。窄窗口优先折叠低频管理项，保持 REC、播放、实时、当前来源和主时间码可见。菜单有可见入口、可访问名称和键盘操作，不采用仅悬停可发现的按钮。

### 4.2 旧入口到新入口

| 现有操作 | 建议位置与行为 | 必须保持 |
| --- | --- | --- |
| 选择/刷新设备、查看实际格式 | 上下文栏“采集设备”摘要打开设置；显示实际格式和后台监测状态 | REC、回听输出期间原有禁用条件；设备错误可见，不只留在菜单内 |
| 录音保存设置、保存目录、预计容量 | 上下文栏“录音设置”摘要；目录管理仍可从库管理区进入 | WAV/MP3/AAC、压缩格式采样率、WAV 位深、保留原始与后台成品规则 |
| 波形倍率、共享时间窗、全长/跟随、循环 | 当前时间轴工具；单独最大化声谱图时提供同源控制 | 操作不发声、所有时间图同步；倍率不改音频 |
| 当前游标时间 | 走带主时间码 | REC 时仍以录音时长为主；其他必要范围/时间差另注明用途，不为去重而删除 |
| 仪器设置/隐藏 | 仪器“更多”菜单 | 最大化保留常驻，隐藏后可从“仪器”恢复；键盘入口等价 |
| 布局切换、保存/重命名/删除、编辑 | 统一布局组：当前布局、更多、编辑/完成 | 自动保存与命名预设分开；拖动与键盘停靠仅在编辑中开放 |
| 文件/连续段/成品查看 | 详情中的版本选择与“查看分析”主操作 | 选中版本只改变详情选择，显式查看/回听才切换工作台；当前来源 ID 可追溯 |
| 重新检查、准备、定位缺失、缓存维护 | 详情更多菜单；异常时提升对应修复动作 | 不可用原因、恢复和丢失信息首层可见；缺失导入项只出现一处重新定位 |
| 导出音频/选区、另存副本 | 主导出入口与一份参数对话框；成品更多菜单保留另存 | 来源版本与范围在提交前明确；取消不得生成错误来源或成功提示 |
| 测量报告、标记、分析图 | 同一报告模态内三个任务分区 | 报告快照与当前素材/目标的区别；图表导出固定来源/游标与元数据 |
| 波形设置、主题、退出确认、帮助、诊断 | 设置模态分类；波形倍率主要留在工作台 | 草稿应用、关闭回退、主题即时预览的既有规则；邮件反馈仍由用户主动触发 |
| A/B 选择与试听、偏移、范围 | 比较面板首层保留选素材、切换、等响度；高级区收起对齐与范围 | A/B 串行回听、独立统计和匹配余量；无参考时引导选择 |
| 目标设置与结果 | 顶部固定设置入口；状态条显示结果及范围，必要时提供语义明确的调整快捷入口 | 图内超限标记、当前/整段口径与短片 LRA 限制；不为“只留一入口”牺牲上下文快捷操作 |

保留多个入口的条件：作用于当前上下文、确有快捷价值、名称/禁用条件一致。例如走带导出当前文件，详情导出选中文件；两者不可因标题相同就删除，也不可让选中项默默代替工作台来源。

### A 批重点：主工作台

- `App`、`WorkbenchSourceBar`、`WorkspaceToolbar`、`FileSourceBar` 的职责先对齐；设备摘要必须能区分当前分析文件与仍在运行的后台采集。
- 保留开始/停止监测的明确文字或等效可访问名称；不能将实时按钮兼作监测开关。菜单里的监测操作在 REC/输出时继续遵循原禁用条件。
- 普通状态上下文工具维持一行；1024×700 可使用更多菜单，但不能隐藏来源、REC、播放、主时间码与退出菜单的路径。
- 波形和响度历史的时间刻度可因独立阅读而保留；不以“数值相同”作为去掉坐标轴的理由。
- 仪器更多菜单不能干扰拖动标题；键盘焦点与 Space/Home/End、菜单键的作用域要明确。

### B 批重点：文件与输出

- 三种身份分开保存：库中选中 ID、详情选择的版本、当前已载入来源。浏览详情/切版本不隐式 `file.open`，更不自动 `playback.play`。
- 继续使用 `preferredSource` 和当前真实播放上下文；同一当前项回听保留实际成品/连续段、游标、选区；快速 A→B 保持最新意图生效。
- 把 `FileAnalysis` 和 `ExportItems` 的呈现统一，不合并它们不同的业务实体；来源/成品的 ready、missing、failed 等状态仍来自主进程。
- 正常状态把重新分析放入更多；失败/取消/缺失时提升相应恢复动作。删除和缓存清理分组，确认明确对象和后果；不改变回收站/引用移除规则。
- 报告任务、手工标记、分析图分别有清晰标题；已有报告是生成时的快照，不能用当前目标或新来源静默替换。切分区不自动生成报告、不重新分析、不打开声卡。
- 分析图导出继续沿用现有 `chart.prepare`/`chart.save` 和来源代次保护，明确暂停与固定游标的副作用；格式切换不应重复导出。

### C 批重点：参数与反馈

- 主题草稿由设置容器持有；切分类保留预览，应用才保存，关闭回退。新增分类只管理当前会话 UI 状态，不顺带新增偏好文件格式。
- 设置中的完整快捷键和诊断仍可发现；诊断复制/导出/邮件反馈保持独立显式动作。完整依赖许可、品牌和上游声明保留。
- A/B 首层突出来源、切换与主要统计；等响度状态、兼容性和不可比较原因持续可见。高级区关闭不重置偏移、联动或范围。
- 3D 的四种相机预设改为单个选择；频率/色阶、相机、时间范围各自复位。隐藏参数或切 2D/3D 不重启音频、重建缓存或清空历史。
- UI88-08 先按“来源 ID＋任务/故障类型”整理提示所有权，避免把后台设备故障与前台文件失败混成一条。全局显示需要立即处理的异常，局部显示该画布不可用原因；局部重试指向同一真实任务。
- 同一任务的完整进度只在主要任务区展开，其他画布可保留简短“分析中”；各数值仍显示分析中/无数据/测量中或静音，不能因去重保留旧数值。
- 原始采集质量、中断、估计静音、质量未知、削波、文件缺失和恢复状态不得仅靠颜色、悬停或高级折叠区表达。普通成功提示可自动收起，尚未解决的故障不得被成功通知覆盖。

## 7 · 状态、尺寸与回归矩阵

每批验证受影响的行；UI88-09 统一复核。状态组合按风险选择，不把所有状态机械做笛卡尔积。

| 场景 | 必须检查 |
| --- | --- |
| 无设备、设备错误、无录音/仅外部素材 | 不显示假正常/假波形；选择设备、导入、恢复入口可达 |
| LIVE 跟随、LIVE 历史、REC 浏览历史 | 实时/监测/REC 分开；历史查看不中断采集；录音中回听、删除与参数修改仍按原限制 |
| 文件准备/暂停/播放/结束 | 来源与游标一致；打开设置/菜单/切报告分区不自动发声；只在显式动作启动回听 |
| 快速 A→B、切设备/目录、REC 准备、后台完成 | 旧异步结果不覆盖新上下文；已有播放意图取消和请求代次保护仍生效 |
| 连续段、原始文件、独立成品、选区 | 名称、采样率、范围与实际来源相符；详情选中项和当前工作台可以不同且清楚标记 |
| 缺失/变化/不可读/可恢复/削波/估计静音/未知质量 | 原有质量与修复动作可发现；外部原文件不因移除引用被删除；清理缓存不删除唯一音频 |
| 报告生成/取消/失败、旧报告、目标变化、标记跳转 | 旧报告身份与目标保留；定位检查来源，跳转保持既有停止输出规则；导出失败可处理 |
| A/B 不完整/不兼容/准备中/匹配启用、快速切换 | 原有范围统计、相位/频谱显示、匹配余量和音量恢复；无同录同播 |
| 2D/3D、单仪器最大化、GPU 失败降级 | 隐藏波形时仍能控制共享时间窗；3D 重试明确；无图表外观参数改写音频 |
| 主题预览、应用、关闭、切分类、保存失败 | 草稿不丢；关闭回退；设置未保存与音频故障分开；狮子月牙/LeoMoon 品牌不随仪表主题变化 |
| 菜单/抽屉/模态/输入焦点 | Tab、Shift+Tab、方向键、Escape、Space、R、Home/End 和 Ctrl+D；输入/菜单不误触全局走带，关闭回到正确入口 |

布局至少覆盖 1024×700、1280×800、1600×900 CSS px；侧栏关闭/打开，1399/1400 CSS px 阈值两侧；长中文/英文名称和所有现有主题。浏览器 deviceScaleFactor 1/1.5/2 仅代表光栅缩放检查，不等于 Windows 系统 DPI 或跨显示器切换。

不以布局尺寸改动顺带升级依赖/协议。Meter v5、Session v2、当前 protocolVersion、缓存键、有界队列与回调约束保持；只有确有数据契约变化才按 03/04/06 另行设计并更新版本。
