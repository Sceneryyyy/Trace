## 行为与数据口径

- 正常打开文件绑定 A，文件库“设为参考”或面板“当前文件 → B”绑定 B。A/B 激活不把 B 重命名为 A；各自持有源描述、范围、视口、游标与监听增益。
- 两边统计使用独立范围缓存，I 不随试听次数累计。差值方向为 A−B；I/LRA 为 LU，TP 为 dB。未就绪、静音、算法/引擎身份不匹配不产生伪造差值，短于 60 秒的 LRA 不用于差值判断。
- 游标联动按整数时间换算，偏移定义为 B=A+offset。越界明确拒绝；“起点”是显式定位且不自动发声。普通 A/B 切换在原先回听中保持试听意图，先关闭旧输出再打开新输出，各自恢复音量。
- 频谱以各自 Hz 网格绘制平均功率，使用 10 log10(power)，不是将功率误当幅度。当前完整文件仪器包可复用；选区频谱重新使用剪裁后的 PCM 范围，不混入选区前的平均窗。显示实际查询时间、Δf 和平均窗是否完整。
- 比较配对属于当前运行，布局持久化。workspace v1/v2/v3 迁移至 v4 后保留旧布局/预设，新参考面板默认隐藏，并提供参考比较布局。

## 取消、持有与并发

ReferenceService 对 A/B 与请求代次独立管理；旧绑定结果不会恢复已删除的来源。AnalysisService 的引用释放只在最后一个消费者离开后取消任务，播放选区不再取消仍被参考/报告使用的分析。

参考持有纳入 SourceRetention；关闭输出时 PlaybackService 保留关闭中的源标识，直到 native playbackClose 完成。绑定参考和打开文件先暂停自动原始源整理，避免与删除已提交的阶段竞争；整理在源 hash 校验后再次核对消费者。没有参考时退出文件视图会释放额外 A 引用，不阻止用户明确选择的原始文件保留策略。

NativeAnalysisQueue 将瞬时 FFT 与时频瓦片统一为两项执行、最多四项等待；前台仪器/瓦片优先，参考合并最新位置。采集/写盘不进入该队列。ReferenceSpectrumService 使用独立可转移数组通道，不进入 TraceState 或命令回复缓存。取消期间拒绝新查询，并等当前 native 回调结束；隐藏、源变化和 REC 不把旧曲线贴到新标签。
