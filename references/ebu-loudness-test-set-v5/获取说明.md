## 测试素材对应用途

| 音频 | 用途和参考值 |
| --- | --- |
| `seq-3341-1`、`seq-3341-2` | 基本响度读数校验；Tech 3341 表 1 中 M/S/I 分别为 −23、−33 LUFS，容差 ±0.1 LU。 |
| `seq-3341-3` 至 `seq-3341-5` | 门限、积分响度测试；预期 I = −23 LUFS，容差 ±0.1 LU。 |
| `seq-3341-6` 的两个版本 | 多声道加权及声道映射；预期 I = −23 LUFS，容差 ±0.1 LU。5 声道版顺序为 L、R、C、Ls、Rs；6 声道 WAVEEX 版加入静音 LFE。 |
| `seq-3341-7_seq-3342-5` | 真实节目，窄响度范围；I = −23 ±0.1 LUFS，LRA = 5 ±1 LU。 |
| `seq-3341-2011-8_seq-3342-6` | 真实节目，宽响度范围；I = −23 ±0.1 LUFS，LRA = 15 ±1 LU。 |
| `seq-3341-9` 至 `seq-3341-14` | 短期响度 S、瞬时响度 M 及其最大值；具体时序和容差见 Tech 3341 表 1。 |
| `seq-3341-15` 至 `seq-3341-23` | 真峰值 TP 测试；具体预期值和非对称容差见 Tech 3341 表 1。 |
| `seq-3342-1` 至 `seq-3342-4` | LRA 测试；预期依次为 10、5、20、15 LU，容差均 ±1 LU。 |
| `EBU-reference_listening_signal_pinknoise_500Hz_2kHz_R128.wav` | 500–2000 Hz 单声道校准噪声，Programme Loudness 为 −23 LUFS；用于设置参考监听电平。 |
| `1kHz Sine -20/-26/-40 LUFS-16bit.wav` | 按文件名标示电平提供的辅助正弦测试信号。 |

每次测量前重置响度仪，保持原始音频电平，不进行归一化或增益处理，并正确设置声道映射。瞬时/短期/真峰值测试须分别使用对应读数，不能统一只看积分响度 I。

包内部分文件原本带有 `.wav.wav` 后缀，本次保留原名。旧 v1 测试集使用 −8 LU 相对门限；后续修订改为 −10 LU，测试时不要混用。

Tech 3341 明确指出测试信号 15–23 电平很高，不应以正常监听音量播放。通过这套最低要求测试，不等于证明响度仪在所有方面均准确。
